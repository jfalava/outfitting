**Syntax:** `outfitting-manager status`

Read-only inspection of the platform, active profile, configuration path, machine ID, source selection, source checkout state, and remote-source cache validity. It does not fetch a source, inspect package upgrades, write configuration, or contact the lockfiles Worker.

| Platform | Profile selection |
| --- | --- |
| Linux | One active Linux profile. |
| macOS | One active macOS profile. |
| Windows | Comma-composed Windows profiles. |
