`status` is read-only. It reports the platform, active [profile selection](/docs/source-configuration/#profiles), config path, [machine ID](/docs/source-configuration/#machine-id), and source checkout state. It does not fetch declarations, inspect for package upgrades, write configuration, or contact the lockfile Worker.

```bash
outfitting-manager status
```

Run `status` before `apply` to verify your active profile, machine ID, and source configuration.

`status` checks the selected local checkout or validated remote snapshot. For a local checkout with Git metadata, it reports the current branch and whether the working tree is clean or dirty. For a remote source, it reports the BYOR map and its explicit repository/ref selection. The manager does not infer or display a built-in source.

## Platform differences

| Platform | Profile field                  | Source state                                         |
| -------- | ------------------------------ | ---------------------------------------------------- |
| macOS    | Selected macOS profile         | Local checkout or explicitly mapped remote snapshot. |
| Windows  | Comma-composed profile bundles | Local checkout or explicitly mapped remote snapshot. |
| Linux    | One active Linux profile       | Local checkout or explicitly mapped remote snapshot. |
