`snapshot` records what is installed so it can be inspected or used by the remote inventory workflow. It does not change the repository's desired configuration.

## `snapshot brew`

On macOS, capture and push installed Homebrew taps, formulae, and casks:

```bash
outfitting-manager snapshot brew
```

## Platform differences

| Platform | Available subcommands | Difference |
| --- | --- | --- |
| macOS | `snapshot brew` | Stores the observed Homebrew inventory. |
| Windows | None | `sync` writes the desired package baseline to `windows.lock.json` instead. |
| Linux | None | Use `diff` or `sync` for package presence; there is no separate snapshot command. |
