`init` creates and validates the local state needed for later commands but does not apply the package baseline. Its exact source contract is platform-specific.

## Platform command

- [Windows init](/docs/cli/windows/init/) — cache the configured Scoop manifest; pass `--no-fetch` to skip prefetching.
- [macOS init](/docs/cli/macos/init/) — validate the sparse source or a local repository checkout.
- [Linux init](/docs/cli/linux/init/) — materialize the Linux source bundle and bootstrap Nix-backed profiles without changing native packages.
- [Linux install](/docs/cli/linux/install/) — hosted bootstrap that runs init and setup.
