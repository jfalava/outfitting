title: Init
description: Validate and select the configured source without changing the machine.
sidebar:

---

`init` prepares runtime state and validates the source declared in [config.toml](/docs/source-configuration/). It does not install, upgrade, remove, or activate packages.

```bash
outfitting-manager init
outfitting-manager --config ~/machine/config.toml init
```

Set `[source] path` for a local checkout, or `repository` and `ref` for remote Git. The selected platform profile comes from `[linux] profile`, `[macos] profile`, or `[windows] profiles`. Remote `--no-refresh` reuses an existing validated `source/` snapshot; local sources are read directly.
