`provision` runs the Alchemy deployment from the monorepo's `iac/` directory, then stores the sync Worker URL and token in the OS keychain unless asked not to.

## `provision`

Run it from the repository root:

```bash
outfitting-manager provision
outfitting-manager provision --no-docs --stack-name OutfittingDev
```

Copy `iac/outfitting.deploy.example.json` to `outfitting.deploy.json` when you need a repeatable configuration:

```bash
outfitting-manager provision --config ./outfitting.deploy.json
```

CLI flags override environment variables, which override the config file, which overrides defaults. Important flags include `--domain`, `--docs`/`--no-docs`, `--stack-name`, `--api-name`, `--router-name`, `--docs-name`, `--installer-name`, `--database-name`, `--kv-title`, `--private-fonts`, `--installer-hosts`, `--token`, and `--skip-configure`.

## Platform differences

| Platform | Invocation                     | Difference                                                                                                                                     |
| -------- | ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| macOS    | `outfitting-manager provision` | Uses the macOS keychain when storing credentials.                                                                                              |
| Windows  | `outfitting-manager provision` | Uses the Windows credential store through Bun secrets.                                                                                         |
| Linux    | `outfitting-manager provision` | Keychain storage may require `libsecret`; use `OUTFITTING_LOCKFILES_URL` and `OUTFITTING_LOCKFILES_TOKEN` when no Secret Service is available. |
