`init` creates the local state root, fetches or selects the macOS source, and validates the repository contract. It does not activate Nix, change Homebrew, repair links, or publish inventory.

```bash
outfit init
outfit init --no-fetch
outfit init --repo ~/src/my-machine-config
```

The default sparse source must contain the paths used by the macOS adapter, including:

```text
system/macos/flake.nix
system/macos/darwin.nix
packages/macos/Brewfile
```

The flake must expose `darwinConfigurations`. The complete allowlisted source closure is checked before setup can apply it. Use `--repo` for a local checkout, including a private or GitHub Enterprise repository; the checkout is read directly and is not uploaded.

## Options

```text
--machine-id <id>                   Override the automatic machine id.
--manifest-base-url <url>           Raw-compatible source URL without the ref.
--manifest-ref <ref>                Git branch, tag, or SHA for the source.
--repo <path>                       Existing local repository checkout.
--no-fetch                          Validate the source already in the state root.
```
