---
title: Snapshot
description: Capture the observed Homebrew inventory on macOS.
audience: macos
sidebar:
  order: 3
---

Capture the currently installed Homebrew taps, formulae, and casks without reconciling them against the managed Brewfile:

```bash
outfitting-manager snapshot brew
```

The snapshot is observed state. It does not change the desired configuration in `packages/macos/Brewfile`.
