The macOS installer provides the compiled `outfitting-manager` and the Zsh profile exposes it as `outfit` and `o`.

## Commands

- [Setup](/docs/cli/macos/setup/) - materialize state and refresh the sparse source.
- [Update](/docs/cli/macos/update/) - apply Nix and Homebrew desired state.
- [Snapshot](/docs/cli/macos/snapshot/) - capture observed Homebrew state.
- [Recover](/docs/cli/macos/recover/) - resume interrupted Nix operations.
- [Sync](/docs/cli/macos/sync/) - push, pull, and inspect remote lockfile state.
- [Shell helpers](/docs/cli/macos/shell/) - maintain the `hm-*` compatibility commands.
- [Remote lockfiles](/docs/cli/lockfiles/) — push, pull, and inspect remote state.
- [Fonts](/docs/cli/fonts/) — manage the shared private-font archive.
- [Provision](/docs/cli/provision/) — deploy Outfitting infrastructure.
- [Upgrade](/docs/cli/upgrade/) — update the installed manager.

Use `outfit` or `outfitting-manager` in the examples on these pages. A bare `outfit` prints manager help.
