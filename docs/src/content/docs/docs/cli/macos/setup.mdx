`setup` prepares the state root, validates the macOS repository contract, activates the declared Nix configuration, and installs the declared Homebrew items.

```bash
outfitting-manager setup
```

The sparse source is stored at `$HOME/.config/outfitting/source`. Setup does not clone the monorepo and does not fetch `system/macos/flake.lock`; Nix uses the canonical lockfile service. Homebrew setup installs missing declarations but does not upgrade or remove unrelated packages.

Use [init](/docs/cli/macos/init/) when you only want to prepare and validate the source.

## Options

```text
--machine-id <id>                   Override the automatic machine id.
--manifest-base-url <url>           Raw-compatible source URL without the ref.
--manifest-ref <ref>                Git branch, tag, or SHA for the source.
--repo <path>                       Validate and use an existing local checkout.
--no-fetch                          Skip fetching; use the existing state-root source.
```

Use `--repo` for another public or private repository that follows the macOS contract. Subsequent `update nix` commands honor the saved checkout without replacing it with sparse source. `OUTFITTING_REPO` takes precedence over the saved path. Normal macOS installation uses the sparse source so the manager remains independent of the repository checkout.

Setup and Nix updates refuse to replace regular files or directories at the Home Manager and nix-darwin symlink destinations. Back up and move conflicting paths before retrying. Existing symlinks, including broken links, can be retargeted.
