On macOS, `sync` is the primary name for the remote inventory and lockfile transport. It exposes the same subcommands as `lockfiles`. The machine id is always inferred (`OUTFITTING_MACHINE_ID` → `config.json` → auto `username:platform`). Omit the kind (or pass `all`) to operate on every kind:

```bash
outfitting-manager sync configure-worker "https://url-to-your-worker"
outfitting-manager sync configure-token
outfitting-manager sync push nix updated-flake.lock
outfitting-manager sync push
outfitting-manager sync pull nix
outfitting-manager sync pull
outfitting-manager sync list
outfitting-manager sync history nix
outfitting-manager sync history
```

See [Lockfiles](/docs/cli/lockfiles/) for remote storage, optimistic concurrency, and the API routes. The `lockfiles` command uses the same remote operations.
