Outfitting has a compiled `outfitting-manager` for macOS, Windows, and Linux. The `outfit` alias is installed by the macOS and Windows profiles.

Run `outfitting-manager --help` or `outfit --help` to see the commands available in the current platform build. The [macOS](/docs/cli/macos/), [Windows](/docs/cli/windows/), and [Linux](/docs/cli/linux/) pages list the complete platform workflows.

## Manager commands

The table covers every top-level `outfitting-manager` command. Platform-only commands are grouped below; their linked pages list each accepted name and option.

| Command     | Purpose                                                                                   | Overview                          |
| ----------- | ----------------------------------------------------------------------------------------- | --------------------------------- |
| `setup`     | Initialize the platform state and apply the first configuration.                          | [Setup](/docs/cli/setup/)         |
| `update`    | Apply package, system, or configuration updates.                                          | [Update](/docs/cli/update/)       |
| `diff`      | Compare live platform state with repository desired state.                                | [Diff](/docs/cli/diff/)           |
| `sync`      | Reconcile Windows/Linux desired state or transport remote lockfiles, depending on the platform. | [Sync](/docs/cli/sync/)           |
| `snapshot`  | Capture observed package state.                                                           | [Snapshot](/docs/cli/snapshot/)   |
| `recover`   | Resume an interrupted managed operation.                                                  | [Recover](/docs/cli/recover/)     |
| `config`    | Configure the Windows repository and route map.                                           | [Config](/docs/cli/config/)       |
| `init`      | Prepare and validate platform state without applying it.                                  | [Init](/docs/cli/init/)           |
| `winget`    | Install or remove a tracked WinGet package.                                               | [WinGet](/docs/cli/winget/)       |
| `scoop`     | Install or remove a tracked Scoop package.                                                | [Scoop](/docs/cli/scoop/)         |
| `lockfiles` | Push, pull, and inspect remote lockfile snapshots.                                        | [Lockfiles](/docs/cli/lockfiles/) |
| `fonts`     | List and manage the private font archive.                                                 | [Fonts](/docs/cli/fonts/)         |
| `provision` | Deploy the Outfitting infrastructure stack.                                               | [Provision](/docs/cli/provision/) |
| `upgrade`   | Check for and install the latest manager release.                                         | [Upgrade](/docs/cli/upgrade/)     |

`lockfiles` remains available for direct remote lockfile transport on macOS and Windows. On macOS it aliases `sync`; on Windows, `sync` itself is reserved for package-profile reconciliation. `outfit update bun` is deprecated; run `bun update -g` directly.

## Platform-only command groups

- [macOS shell helpers](/docs/cli/macos/shell/) — `hm-build`, `hm-test`, `hm-dry`, `hm-switch`, `hm-sync`, `hm-update`, `hm-rollback`, `hm-clean`, and `hm-recover`.
- [Linux install](/docs/cli/linux/install/) — the architecture-selecting `linux.jfa.dev` binary bootstrap.
- [Linux Home Manager](/docs/cli/linux/home-manager/) — `update nix` and `hm-build|test|dry|switch|sync|update|rollback|clean`.
- [Linux maintenance](/docs/cli/linux/maintenance/) — `update all|apt|pacman`, `diff`, `sync`, and `bun update -g`.
