`validate` checks the single machine-local [config.toml](/docs/source-configuration/) and the selected profile's declared manifests and paths without applying changes.

```bash
outfitting-manager validate
outfitting-manager --config ~/machine/config.toml validate
```

The configuration selects `[source] path` or remote `repository` plus `ref`, and `[linux] profile`, `[macos] profile`, or `[windows] profiles`. Declaration paths must remain inside the source root. Linux supports apt, pacman, and Nix; macOS supports Nix, Brewfile, and fonts; Windows supports WinGet and optional shared components. For details see [Linux](/docs/source-configuration/byor/linux/), [macOS](/docs/source-configuration/byor/macos/), and [Windows](/docs/source-configuration/byor/windows/).
