title: Init

`init` creates the Windows state root and caches the configured Scoop manifest. It does not apply package state.

```powershell
outfitting-manager init
outfitting-manager init --no-fetch
```

Use `--no-fetch` to write or refresh configuration without prefetching manifests. Other options are `--machine-id`, `--manifest-base-url`, and `--manifest-ref`; source overrides are persisted for later runs.
