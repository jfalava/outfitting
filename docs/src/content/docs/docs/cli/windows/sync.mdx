---
title: Sync
description: Reconcile Windows package profiles and the unified machine lock.

---

`sync` fetches the selected profile files from the configured raw source, reconciles WinGet and Scoop, materializes the configured PowerShell profile, and writes `windows.lock.json`.

```powershell
outfit sync
outfit sync --profile base,dev
outfit sync --profile base --winget-only
outfit sync --no-push
```

Options are `--profile`, `--winget-only`, and `--no-push`. Regular profiles now include their Microsoft Store entries, marked as `msstore:<id>` in the manifest, and install those entries with `--source msstore`. Existing `msstore-*` profiles remain available as Store-only compatibility profiles during migration. To move an existing machine to the unified baseline, run `outfit sync --profile base` (or the matching regular profile) once. `--no-push` keeps the lock local. Untracked native WinGet and Scoop installs remain unmanaged.

Each sync lists tracked packages outside the selected baseline and asks before removing them. Declining aborts before package operations or lock writes.
