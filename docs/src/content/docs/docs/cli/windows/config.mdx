Run the interactive wizard to configure a compatible repository, its Windows artifact routes, and the profiles used on a new machine:

```powershell
outfitting-manager config
```

Bare `config` remains the interactive wizard. For scripted setup, pass one or more flags; the wizard is skipped and only the fields supplied are changed. Existing values for omitted fields are preserved.

```powershell
outfitting-manager config --repo https://github.com/me/my-fork --ref main --winget-profile-path packages/windows/{profile}.json
```

Available flags:

| Flag | Configured value |
| --- | --- |
| `--repo <url>` | Repository URL. Public `github.com` URLs are converted to the raw-content source URL. GitHub Enterprise URLs stay on that host and are read with `gh`. |
| `--ref <ref>` | Repository branch, tag, or commit. |
| `--winget-profile-path <path>` | WinGet profile route template. |
| `--scoop-path <path>` | Scoop manifest route. |
| `--powershell-profile-path <path>` | PowerShell profile route. |
| `--font-list-path <path>` | FontGet list route. |
| `--registry-path <path>` | Registry tweaks directory route. |
| `--default-profiles <profiles>` | Comma-separated default WinGet profiles. |

The wizard saves `%USERPROFILE%\.config\outfitting\config.json`. It configures the raw source URL and ref plus these repository-relative routes:

- `wingetProfilePath` - a `{profile}` template for WinGet files.
- `scoopPath` - the Scoop package manifest.
- `powershellProfilePath` - the cached PowerShell profile.
- `fontListPath` - the public FontGet list.
- `registryPath` - the registry tweaks directory.
- `defaultProfiles` - profiles used when no machine selection exists.

Routes cannot escape the repository, and profile names must contain only letters, numbers, `.`, `_`, or `-`. The default profile is `base`.
