---
title: Packages
description: Track manual WinGet and Scoop package operations on Windows.

---

Install or remove one or more packages and record each operation in `windows.lock.json`:

```powershell
outfitting-manager winget install Git.Git
outfitting-manager winget uninstall Git.Git
outfitting-manager scoop install extras/fzf
outfitting-manager scoop uninstall fzf
```

Pass `--no-sync` to keep the updated lockfile local instead of pushing it to the Worker. WinGet arguments are package IDs; Scoop accepts package names and bucket-qualified names.

These commands track only operations made through `outfitting-manager`. Native package-manager installs remain unmanaged until they are included in a selected profile or explicitly tracked.
