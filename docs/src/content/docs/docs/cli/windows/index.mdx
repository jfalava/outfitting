The Windows installer provides the compiled `outfitting-manager.exe`; the PowerShell profile puts it on `PATH`. The post-install script runs `init` and `apply` against the configured TOML source. Its separate font downloads still accept legacy raw-route inputs.

## Configuration

Select `[windows] profiles` and a local or remote `[source]` in `config.toml`. See [Windows configuration](/docs/source-configuration/byor/windows/) and [validate](/docs/cli/validate/).

## Commands

- [Init](/docs/cli/init/) - select and validate an explicit source.
- [Validate](/docs/cli/validate/) - check `config.toml` without applying it.
- [Source configuration](/docs/source-configuration/) — configure a local or remote source.
- [Apply](/docs/cli/apply/) - reconcile selected local profiles, optionally pruning Outfitting-owned packages.
- [Update](/docs/cli/update/) - upgrade installed packages through one selected manager.
- [Diff](/docs/cli/diff/) - compare live WinGet and Scoop state with the repository.
- [Sync](/docs/cli/sync/) - push, pull, and inspect remote state.
- [Status](/docs/cli/status/) - show effective configuration without changing it.
- [Packages](/docs/cli/windows/packages/) - track manual WinGet and Scoop operations.
- [WinGet](/docs/cli/windows/winget/) and [Scoop](/docs/cli/windows/scoop/) - manager-specific package operations.
- [Fonts](/docs/cli/fonts/) — manage the shared private-font archive.
- [Provision](/docs/cli/provision/) — deploy Outfitting infrastructure.
- [Self-update](/docs/cli/self-update/) — update the installed manager binary.

Windows combines the names in `[windows] profiles`. Undeclared shared components are skipped. See [source configuration](/docs/source-configuration/) for selection rules.
