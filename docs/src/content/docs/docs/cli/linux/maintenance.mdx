## Generic Linux

Upgrade the system package set, then install only **missing** managed packages for the selected profile (default: `linux.profile` from `config.json`, else `generic-linux`):

```bash
outfitting-manager update all
```

Use `update apt` or `update pacman` to select a manager explicitly, or pass `--package-manager apt|pacman` to `update all`. Pass `--profile` to override the persisted profile; use `oci-agents` only on the managed OCI host and `ubuntu-wsl` only inside Ubuntu WSL.

For Home Manager on `oci-agents` / `ubuntu-wsl` (same actions as macOS):

```bash
outfitting-manager update nix         # switch
outfitting-manager update nix build
outfitting-manager update nix switch
```

Check or install only missing declared packages with:

```bash
outfitting-manager diff --manager apt
outfitting-manager sync apt
```

Linux `diff` and `sync` use the same profile resolution and the correct package-list path per profile (including `packages/ubuntu-wsl/apt.txt`). Both report or install missing declared packages only and preserve every unrelated package already installed on the host.

## WSL

Run the complete local maintenance sequence with:

```bash
update-all
```

It refreshes APT packages, applies the Home Manager update, cleans old Nix generations, and updates global Bun packages.

To run the hosted update-only path from an existing shell:

```bash
remote-update
```

This is equivalent to `curl -L https://wsl.jfa.dev | bash -s -- --update-only`.

For global Bun packages, use Bun directly:

```bash
bun update -g
```
