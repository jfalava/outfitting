## Generic Linux

Update the detected native package manager and the `generic-linux` profile:

```bash
outfitting-manager update all
```

Use `update apt` or `update pacman` to select a manager explicitly, or pass `--package-manager apt|pacman` to `update all`. Use `--profile oci-agents` only on the managed OCI host.

Check or install only missing declared packages with:

```bash
outfitting-manager diff --manager apt
outfitting-manager sync apt
```

Linux `diff` reports missing declared packages only. Linux `sync` installs those missing packages and preserves every unrelated package already installed on the host; it never tries to make the complete APT inventory match the repository.

## WSL

Run the complete local maintenance sequence with:

```bash
update-all
```

It refreshes APT packages, applies the Home Manager update, cleans old Nix generations, and updates global Bun packages.

To run the hosted update-only path from an existing shell:

```bash
remote-update
```

This is equivalent to `curl -L https://wsl.jfa.dev | bash -s -- --update-only`.

For global Bun packages, use Bun directly:

```bash
bun update -g
```
