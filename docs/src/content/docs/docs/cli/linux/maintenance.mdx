## Packages

Upgrade the system set, then install only **missing** managed packages (profile from `config.json` `linux.profile`, else `generic-linux`):

```bash
outfitting-manager update all
```

```bash
outfitting-manager update apt
outfitting-manager update pacman
outfitting-manager update all --package-manager apt
outfitting-manager update all --profile ubuntu-wsl
```

```bash
outfitting-manager diff
outfitting-manager sync apt
```

`diff` and `sync` only care about declared packages; everything else on the host is ignored.

## Home Manager

On Nix-backed profiles:

```bash
outfitting-manager update nix         # lists actions
outfitting-manager update nix build
outfitting-manager update nix switch  # build + activate
```

Shell helpers: `hm-build`, `hm-test`, `hm-dry`, `hm-switch`, `hm-sync`, `hm-update`, `hm-rollback`, `hm-clean`. See [Home Manager](/docs/cli/linux/home-manager/).

## Bun

bun update -g
