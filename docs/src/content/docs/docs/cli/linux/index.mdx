Linux uses the compiled `outfitting-manager` binary. It detects `/etc/os-release` and the installed package-manager executable, selecting **apt** for Debian-family distributions and **pacman** for Arch-family distributions.

Install with:

```bash
curl -L linux.jfa.dev | bash
```

The bootstrap selects the Linux x64 or arm64 release, verifies its checksum, and runs the manager. State is stored under `~/.config/outfitting`.

Initialize and apply the default profile separately when needed:

```bash
outfitting-manager init
outfitting-manager setup --no-fetch
```

`init` materializes the sparse source and records `linux.profile` in `config.json` without changing native packages (Nix-backed profiles also apply Home Manager). `setup` installs missing declared packages and re-runs the profile bootstrap. Use `update` for full upgrades.

## Profiles

| Profile | Packages | Home Manager |
| --- | --- | --- |
| `generic-linux` (default) | `packages/linux/generic-linux.txt` | No |
| `ubuntu-wsl` | `packages/ubuntu-wsl/apt.txt` | `system/ubuntu-wsl` |
| `oci-agents` | `packages/linux/oci-agents.txt` | `system/oci-agents` |

```bash
outfitting-manager init --profile generic-linux
outfitting-manager init --profile ubuntu-wsl
outfitting-manager init --profile oci-agents --repo ~/code/outfitting
outfitting-manager update all --package-manager apt
```

Without `--repo`, the sparse source is `$HOME/.config/outfitting/source`. Set `OUTFITTING_REPO` or pass `--repo` for a full checkout.

## Commands

- [Init](/docs/cli/linux/init/) — materialize source and record the profile.
- [Install](/docs/cli/linux/install/) — hosted bootstrap.
- [Home Manager](/docs/cli/linux/home-manager/) — `update nix` and `hm-*` helpers.
- [Maintenance](/docs/cli/linux/maintenance/) — `update`, `diff`, `sync`.
