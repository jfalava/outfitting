Linux uses the compiled `outfitting-manager` binary. It detects `/etc/os-release` and the installed package-manager executable, selecting modern `apt` for Debian-family distributions and `pacman` for Arch-family distributions. The `ubuntu-wsl` profile shares this command surface with the existing WSL shell helpers.

Install the generic Linux binary bootstrap with:

```bash
curl -L linux.jfa.dev | bash
```

The bootstrap selects the Linux x64 or arm64 release, verifies its checksum, and runs the manager. The manager stores state under `~/.config/outfitting`.

Initialize and apply the default profile separately:

```bash
outfitting-manager init
outfitting-manager setup --no-fetch
```

`init` fetches the complete Linux source bundle and caches the selected profile without changing native packages. For Nix-backed profiles it also applies Home Manager from the local source. `setup` consumes that cached profile, installs missing declared packages, and applies the profile bootstrap again. It does not upgrade the whole system; use `update` for that. Pass `--no-fetch` to `init` only when the local source and cached manifests already exist.

To override detection or select a profile:

```bash
outfitting-manager update all --package-manager apt
outfitting-manager init --profile oci-agents
outfitting-manager setup --profile oci-agents --repo ~/code/outfitting --no-fetch
outfitting-manager init --profile ubuntu-wsl
outfitting-manager setup --profile ubuntu-wsl --repo ~/.config/outfitting/repo --no-fetch
```

The Linux source bundle is stored at `~/.config/outfitting/source` and includes the `oci-agents` and `ubuntu-wsl` flakes, lockfiles, Zsh files, common modules, dotfiles, Nix packages, and native package manifests. The profiles run their Nix/Home Manager bootstrap after initialization and after native package setup. Pass `--repo` to use and update another full checkout. `ubuntu-wsl` uses the existing `packages/ubuntu-wsl/apt.txt` package manifest and `system/ubuntu-wsl` Home Manager configuration.

## Commands

- [Init](/docs/cli/linux/init/) - materialize the complete Linux source bundle and bootstrap Nix-backed profiles without changing native packages.
- [Setup](/docs/cli/linux/) - apply the selected apt or pacman package profile.
- [Install](/docs/cli/linux/install/) - run the generic Linux or WSL hosted installer.
- [Home Manager](/docs/cli/linux/home-manager/) - apply, update, roll back, or clean Nix state.
- [Maintenance](/docs/cli/linux/maintenance/) - run native Linux updates or the combined WSL helpers.

Without `--repo`, Linux profiles use the sparse source at `$HOME/.config/outfitting/source`. Set `OUTFITTING_REPO` or pass `--repo` to use and update another full checkout.
