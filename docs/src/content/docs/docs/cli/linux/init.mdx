`init` creates the local state root, records the selected profile in `config.json` as `linux.profile`, and fetches a **profile-scoped** sparse source into `~/.config/outfitting/source`. Generic Linux materializes only its package list; `oci-agents` and `ubuntu-wsl` each pull shared Unix/Nix modules plus that profile's flake, bootstrap, and package manifests — never the macOS closure or the other Linux profile. For Nix-backed profiles, `init` applies Home Manager from that local source. Use `--repo` to choose and update an existing full checkout instead.

```bash
outfitting-manager init
outfitting-manager init --profile oci-agents
outfitting-manager init --profile ubuntu-wsl
outfitting-manager init --profile oci-agents --repo ~/code/outfitting
outfitting-manager init --no-fetch
```

Use [setup](/docs/cli/linux/) after initialization to apply the cached native package profile. The hosted Linux installer runs both steps automatically. The Nix-backed profiles expect Nix to already be installed. The OCI bootstrap also installs its harnesses, sets the login shell to zsh, ensures the user systemd session bus, starts Amp/T3/OpenCode, and the Zsh plugin starts a local `ssh-agent` (with auto-load of the elliptic GitHub key) when forwarding is absent; the WSL bootstrap only applies Home Manager configuration. Open a new SSH session after the first OCI activation so the zsh profile loads.

## Options

```text
--profile <generic-linux|oci-agents|ubuntu-wsl>  Package profile to cache.
--machine-id <id>                     Override the automatic machine id.
--manifest-base-url <url>             Raw-compatible source URL without the ref.
--manifest-ref <ref>                  Git branch, tag, or SHA for the source.
--repo <path>                         Optional full checkout to update for a Nix-backed profile.
--no-fetch                            Use the existing cached profile.
```
