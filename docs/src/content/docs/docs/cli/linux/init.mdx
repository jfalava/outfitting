`init` creates the local state root, records the selected profile in `config.json` as `linux.profile`, and fetches a **profile-scoped** sparse source into `~/.config/outfitting/source`.

- `generic-linux` — package list only.
- `ubuntu-wsl` / `oci-agents` — shared Unix/Nix modules plus that profile’s flake, bootstrap, and manifests.

For Nix-backed profiles, `init` also applies Home Manager from the local source. Use `--repo` to point at a full checkout instead of the sparse tree.

```bash
outfitting-manager init
outfitting-manager init --profile generic-linux
outfitting-manager init --profile ubuntu-wsl
outfitting-manager init --profile oci-agents --repo ~/code/outfitting
outfitting-manager init --no-fetch
```

Then run [setup](/docs/cli/linux/) (or let the hosted installer do both).

## Options

```text
--profile <generic-linux|ubuntu-wsl|oci-agents>  Package profile to cache.
--machine-id <id>                     Override the automatic machine id.
--manifest-base-url <url>             Raw-compatible source URL without the ref.
--manifest-ref <ref>                  Git branch, tag, or SHA for the source.
--repo <path>                         Full checkout instead of sparse source.
--no-fetch                            Use the existing cached profile.
```
