```bash
curl -L linux.jfa.dev | bash
```

Supports Linux x64 and arm64. The script installs `outfitting-manager`, runs `init` and `setup`, detects apt or pacman, and applies the selected profile (default: `generic-linux`).

## Profile examples

```bash
curl -L linux.jfa.dev | bash -s -- --profile generic-linux
curl -L linux.jfa.dev | bash -s -- --profile ubuntu-wsl
curl -L linux.jfa.dev | bash -s -- --profile oci-agents
```

Nix-backed profiles expect Nix to be available on the machine (or installed by that profile’s bootstrap). See [init](/docs/cli/init/) for `--repo` and source flags.
