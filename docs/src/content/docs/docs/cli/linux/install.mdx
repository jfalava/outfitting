## Generic Linux

Run the architecture-selecting binary bootstrap:

```bash
curl -L linux.jfa.dev | bash
```

It supports Linux x64 and arm64 and delegates installation to `outfitting-manager`, which detects apt or pacman. The installer fetches the complete local source bundle, applies the selected Nix/Home Manager profile when applicable, and installs the declared native packages. The `oci-agents` and `ubuntu-wsl` profiles can be selected with `--profile`.

```bash
curl -L linux.jfa.dev | bash -s -- --profile oci-agents
curl -L linux.jfa.dev | bash -s -- --profile ubuntu-wsl
```

## WSL

Run the hosted installer from an interactive WSL shell:

```bash
curl -L wsl.jfa.dev | bash
```

The script accepts these modes:

```bash
curl -L wsl.jfa.dev | bash -s -- --full-install  # APT, Docker, HashiCorp, Nix, and Home Manager
curl -L wsl.jfa.dev | bash -s -- --update-only   # APT-only update path
curl -L wsl.jfa.dev | bash -s -- --nix-only      # Nix and Home Manager path
```

`--full` and `--apt-only` remain accepted aliases. Profile-selection flags are obsolete because WSL has one personal configuration.
