```bash
curl -L linux.jfa.dev | bash
```

The hosted script supports Linux x64 and arm64 and installs `outfitting-manager`.

> [!WARNING]
> The current bootstrap may still run `init` with an implicit built-in profile. Configure `config.toml` before manual manager setup; the installer needs a separate update.

Configure a local checkout or remote Git source in `config.toml`. See [Linux configuration](/docs/source-configuration/byor/linux/) and the [source configuration overview](/docs/source-configuration/).
