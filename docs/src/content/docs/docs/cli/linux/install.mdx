```bash
curl -L linux.jfa.dev | bash
```

The hosted script supports Linux x64 and arm64 and installs `outfitting-manager`. Its default profile is `generic-linux`; choose another configured profile with `--profile`:

```bash
curl -L linux.jfa.dev | bash -s -- --profile oci-agents
```

Configure `config.toml` with the selected profile and a local or remote source before running the installer. It runs `init`, then `apply` and `nix switch`; `--if-configured` lets those operations skip undeclared native or Nix backends. See [Linux configuration](/docs/source-configuration/byor/linux/) and the [source configuration overview](/docs/source-configuration/).
