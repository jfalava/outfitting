`scoop` installs or removes packages and records each operation in `windows.lock.json`. It is available only in the Windows manager build.

## `scoop install`

Install one or more Scoop package names:

```powershell
outfitting-manager scoop install extras/fzf
```

## `scoop uninstall`

Remove one or more Scoop package names:

```powershell
outfitting-manager scoop uninstall fzf
```

Both subcommands accept `--no-sync` to update the local lock without uploading it. Native Scoop operations remain unmanaged unless they are included in a selected profile or run through this command.

## Platform differences

| Platform | Availability | Difference |
| --- | --- | --- |
| macOS | Not available | Use `update brew` or `update nix`. |
| Windows | Available | Operations are recorded in `windows.lock.json` and normally pushed to the Worker. |
| Linux | Not available | Use `update apt` or `update pacman`. |
