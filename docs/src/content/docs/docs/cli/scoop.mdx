---
title: Scoop
description: Track manual Scoop package operations in the Windows machine lock.
sidebar:
  order: 9
---

`scoop` installs or removes one or more packages and records each operation in `windows.lock.json`. It is available in the Windows manager build only.

See [Windows package commands](/docs/cli/windows/packages/) for `install`, `uninstall`, `--no-sync`, and the lock-recording behavior.
