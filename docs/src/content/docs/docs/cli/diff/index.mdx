`diff` is read-only. It compares the live machine with the repository manifests configured for the current platform. It does not install, remove, activate, write lockfiles, or push remote state.

```sh
outfit diff
```

Use `--manager` to inspect one source, `--profile` to select Windows profiles, `--offline` to use cached manifests, or `--json` for automation:

```sh
outfit diff --manager brew
outfit diff --profile base,dev
outfit diff --offline --json
```

## Compared state

- macOS compares Homebrew taps, direct formulae, casks, and a Nix dry-build plan.
- Windows compares selected WinGet profiles and Scoop buckets/packages.

Repository package manifests do not generally pin versions, so the command reports missing, extra, and changed entries rather than version drift. Homebrew dependencies are omitted by comparing direct formulae with `brew leaves`.

The command exits successfully when the compared state matches. It exits nonzero when differences are found or a required comparison is unavailable.
