`diff` is read-only. It compares the live machine with the configured source and does not install, remove, activate, write lockfiles, or push remote state.

## `diff`

```bash
outfitting-manager diff
outfitting-manager diff --manager brew
outfitting-manager diff --profile base,dev
outfitting-manager diff --offline --json
```

## Options

| Option             | Purpose                                                                            |
| ------------------ | ---------------------------------------------------------------------------------- |
| `--manager <name>` | Compare one manager instead of the complete platform set.                          |
| `--profile <name>` | Select a profile using the [platform profile rules](/docs/source-configuration/).  |
| `--offline`        | Reuse only the validated local remote-source snapshot and skip remote comparisons. |
| `--refresh`        | Linux only: refresh the configured source before comparing declarations.           |
| `--json`           | Print the result as JSON.                                                          |

The command exits successfully when the compared state matches. It exits nonzero when differences are found or a required comparison is unavailable.

## Platform differences

| Platform | Compared state                                             | Notes                                                                            |
| -------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------- |
| macOS    | Homebrew taps, formulae, casks, and the active Nix system. | A built but not activated Nix system still differs from `/run/current-system`.   |
| Windows  | Selected WinGet profiles and Scoop buckets/packages.       | Store entries use the `msstore:<id>` manifest form.                              |
| Linux    | Declared apt or pacman packages.                           | Only missing declared packages matter; unrelated installed packages are ignored. |
