`fonts` lists, publishes, and removes licensed fonts stored in the private R2 archive. Incoming files must be OpenType (`.otf`, `.ttf`, or `.ttc`).

## `fonts configure-endpoint`

Store an R2 S3 HTTPS endpoint or Cloudflare account id:

```bash
outfitting-manager fonts configure-endpoint
outfitting-manager fonts configure-endpoint <account-id-or-endpoint>
```

## `fonts configure-credentials`

Prompt for and store the R2 access key and secret:

```bash
outfitting-manager fonts configure-credentials
```

## `fonts list`

List published font faces. Use `--repopulate` to rebuild the inventory from the live archive first:

```bash
outfitting-manager fonts list
outfitting-manager fonts list --repopulate
```

## `fonts repopulate`

Rebuild the lockfiles inventory from the live R2 archive. Use `--dry-run` to compare without writing:

```bash
outfitting-manager fonts repopulate --dry-run
outfitting-manager fonts repopulate
```

## `fonts publish`

Merge fonts from a directory into the archive:

```bash
outfitting-manager fonts publish ~/Downloads/ibm-plex-sans --dry-run
outfitting-manager fonts publish ~/Downloads/ibm-plex-sans --yes
```

Use `--replace` to overwrite an existing archive path, `--keep-names` to keep sanitized filenames, `--allow-system-names` for reserved families, and `--repopulate` to refresh inventory first.

## `fonts remove`

Remove faces by family, archive path, or PostScript name:

```bash
outfitting-manager fonts remove ibm-plex-sans --family --dry-run
outfitting-manager fonts remove ibm-plex-sans --family --yes
```

Use `--family` to remove whole families. `--dry-run`, `--yes`, and `--repopulate` have the same meaning as for `publish`.

## Platform differences

| Platform | Availability | Difference                                                                         |
| -------- | ------------ | ---------------------------------------------------------------------------------- |
| macOS    | Available    | Fonts can be installed by the macOS post-install workflow after publishing.        |
| Windows  | Available    | Fonts can be extracted by the Windows post-install workflow after publishing.      |
| Linux    | Available    | The archive operations are the same; installation is outside this command's scope. |
