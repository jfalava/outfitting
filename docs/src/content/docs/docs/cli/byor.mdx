The `byor` command has been retired. This route is retained for existing links. Configure a local checkout or remote Git repository in the single machine-local [`config.toml`](/docs/source-configuration/) instead. Remote sources use `[source] repository` and `ref`; local sources use `[source] path`.

To convert legacy machine settings once, run `outfitting-manager config migrate`. Normal commands do not consult the old JSON files. Use `outfitting-manager source path` when a script needs the resolved source directory.
