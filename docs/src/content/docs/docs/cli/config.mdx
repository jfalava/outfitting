`config` is the interactive Windows command for selecting a compatible repository, its artifact routes, and the default package profiles. Other platforms configure their source through their setup workflow or environment variables.

## Platform command

- [Windows config](/docs/cli/windows/config/) — run `outfit config` to write `%USERPROFILE%\.config\outfitting\config.json`.
- [macOS setup](/docs/cli/macos/setup/) — use `setup --repo`, `--manifest-base-url`, and `--manifest-ref` for macOS source settings.
- [Linux install](/docs/cli/linux/install/) — hosted bootstrap; use `init`/`setup` flags for source overrides.
