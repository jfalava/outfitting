`config` is an interactive Windows wizard. It saves the repository source, artifact routes, machine id, and default WinGet profiles to `%USERPROFILE%\.config\outfitting\config.json`.

## `config`

```powershell
outfitting-manager config
```

The wizard asks for the raw repository URL and ref, then these repository-relative routes:

- WinGet profile template containing `{profile}`.
- Scoop manifest.
- PowerShell profile.
- FontGet list.
- Registry tweaks directory.
- Default comma-separated profiles such as `base,dev`.

Routes cannot escape the repository, and profile names may contain only letters, numbers, `.`, `_`, and `-`.

## Platform differences

| Platform | Configuration command | Difference |
| --- | --- | --- |
| macOS | None | Configure source overrides with `init` or `setup` flags such as `--repo` and `--manifest-ref`. |
| Windows | `config` | The interactive wizard owns the Windows route map and default profiles. |
| Linux | None | Configure the Linux profile with `init`/`setup --profile` or use `--repo` for a full checkout. |
