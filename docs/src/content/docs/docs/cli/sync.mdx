`sync` is the same remote-state transport on macOS, Windows, and Linux. It never installs, upgrades, or removes packages. There is no top-level `lockfiles` alias.

## Invoke `sync`

```bash
outfitting-manager sync <subcommand> [flags]
```

Sync uses the configured [machine ID](/docs/cli/profiles/#machine-id); it is not a positional argument.

All subcommands below are available on every platform. Configure the Worker and token once before pushing or pulling.

### `sync configure-worker`

Store the lockfiles Worker URL.

```bash
outfitting-manager sync configure-worker https://example.com/api
```

### `sync configure-token`

Prompt for and store the Worker API token.

```bash
outfitting-manager sync configure-token
```

On headless Linux systems without `libsecret` and a running Secret Service, use environment variables instead:

```bash
export OUTFITTING_LOCKFILES_URL="https://outfitting.jfa.dev/api"
export OUTFITTING_LOCKFILES_TOKEN="..."
```

Environment values take precedence over keychain values.

### `sync push`

Upload a local lockfile. An explicit kind requires a file path. Omit the kind, or pass `all`, to scan known lock paths relative to the current working directory, not the Outfitting state root.

```bash
outfitting-manager sync push nix updated-flake.lock
outfitting-manager sync push homebrew-inventory ~/.config/outfitting/homebrew-inventory.txt
```

Use `--if-match <sha256>` for an optimistic-concurrency check. A stale expected hash is rejected without advancing the remote head.

### `sync pull`

Download one lockfile or all tracked kinds. Known kinds get a default output path; pass an explicit path when needed.

```bash
outfitting-manager sync pull nix
outfitting-manager sync pull windows restored-windows.lock.json
outfitting-manager sync pull
```

### `sync list`

List lockfile kinds tracked for the inferred machine.

### `sync history`

Show version history for one kind or, when omitted, every tracked kind.

```bash
outfitting-manager sync history nix
outfitting-manager sync history
```

## Platform differences

| Platform | Meaning of `sync`                                                      | Invocation                                                                          |
| -------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| macOS    | Remote push, pull, list, history, and credential configuration.        | `outfitting-manager sync push nix updated-flake.lock`                               |
| Windows  | Identical remote transport; package reconciliation belongs to `apply`. | `outfitting-manager sync push windows "$HOME/.config/outfitting/windows.lock.json"` |
| Linux    | Identical remote transport; package reconciliation belongs to `apply`. | `outfitting-manager sync list`                                                      |
