`lockfiles` sends generated machine state to the lockfiles Worker. The machine id is inferred from `OUTFITTING_MACHINE_ID`, `config.json`, or the automatic `user:arch-os` value.

Use the same subcommands below through `sync`. On macOS, `sync` is the primary name; on Windows and Linux, `lockfiles` makes the remote transport explicit.

## `lockfiles configure-worker`

Store the Worker URL in the OS keychain:

```bash
outfitting-manager lockfiles configure-worker https://example.com/api
```

## `lockfiles configure-token`

Prompt for and store the bearer token:

```bash
outfitting-manager lockfiles configure-token
```

On headless Linux systems without `libsecret` and a running Secret Service, use environment variables instead:

```bash
export OUTFITTING_LOCKFILES_URL="https://outfitting.jfa.dev/api"
export OUTFITTING_LOCKFILES_TOKEN="..."
outfitting-manager sync list
```

Environment values take precedence over keychain values. Bun's Linux keychain backend otherwise requires `libsecret` and a running Secret Service such as GNOME Keyring or KWallet.

## `lockfiles push`

Upload a local lockfile. Omit the kind, or pass `all`, to push every known local default path that exists:

```bash
outfitting-manager lockfiles push nix updated-flake.lock
outfitting-manager lockfiles push
```

Pass `--if-match <sha256>` to reject the push if another client has advanced the remote version.

## `lockfiles pull`

Download one lockfile or all kinds tracked for this machine:

```bash
outfitting-manager lockfiles pull nix
outfitting-manager lockfiles pull windows restored-windows.lock.json
outfitting-manager lockfiles pull
```

Known kinds have inferred output paths. Pass an explicit path for another kind.

## `lockfiles list`

List the lockfile kinds tracked for this machine:

```bash
outfitting-manager lockfiles list
```

## `lockfiles history`

Show versions for one kind or every tracked kind:

```bash
outfitting-manager lockfiles history nix
outfitting-manager lockfiles history
```

## Platform differences

| Platform | Primary command | State commonly transported |
| --- | --- | --- |
| macOS | `sync` (`lockfiles` is an alias) | The canonical Nix lock and Homebrew inventory. |
| Windows | `lockfiles` (`sync` is package reconciliation) | `windows.lock.json`; normal package sync also uploads it. |
| Linux | `lockfiles` or lockfile subcommands below `sync` | Any configured lockfile kind; package `sync` remains local apt/pacman reconciliation. |
