`recover` resumes a manager-owned checkpoint instead of starting an update over.

## `recover nix`

On macOS, resume an interrupted nix-darwin activation or lock publication:

```bash
outfitting-manager recover nix
```

The checkpoint is stored under `$XDG_STATE_HOME/outfitting/nix-lock-recovery`, or `$HOME/.local/state/outfitting/nix-lock-recovery` by default. The `hm-recover` shell helper invokes the same recovery path.

## Platform differences

| Platform | Available subcommands | Difference |
| --- | --- | --- |
| macOS | `recover nix` | Resumes and publishes a pending nix-darwin operation. |
| Windows | None | Retry `sync`, `setup`, or the relevant package-manager command. |
| Linux | None | Retry the package or Home Manager command; rollback is handled by the platform's Nix tools. |
