`setup` validates the selected BYOR source, then installs missing packages and applies its declarative configuration. A source must be a local checkout with root `outfitting.json` or a remote Git source configured in `byor.json`. There are no built-in manifests or raw URL routes.

## Usage

```bash
outfitting-manager setup --repo ~/src/machine-config --profile workstation
outfitting-manager setup --profile workstation
outfitting-manager setup --profile workstation --no-refresh
```

Use `--repo <path>` or `OUTFITTING_REPO` to select a local checkout. Otherwise, configure a remote with [`outfitting-manager byor`](/docs/cli/byor/). `--no-refresh` uses the previously validated local snapshot; it does not fetch. Local checkouts are never refreshed from a Git remote.

Native package setup installs missing entries but does not upgrade or remove installed packages. Nix activation is declarative and may change managed system state. Use [`init`](/docs/cli/init/) to validate/select a source without applying it, [`apply`](/docs/cli/apply/) for package reconciliation, and [`update`](/docs/cli/update/) to upgrade installed software.

## Common options

| Option                          | Purpose                                                               |
| ------------------------------- | --------------------------------------------------------------------- |
| `--repo <path>`                 | Select a local checkout; it takes precedence over `byor.json`.        |
| `--profile <name>`              | Select a BYOR profile. Windows accepts comma-separated profile names. |
| `--machine-id <id>`             | Override the machine identity used for remote state.                  |
| `--no-refresh`                  | Use the existing validated remote snapshot.                           |
| `--package-manager apt\|pacman` | Linux only: override package-manager detection.                       |

## Platform behavior

| Platform | Setup applies                                                                                                   |
| -------- | --------------------------------------------------------------------------------------------------------------- |
| macOS    | The declared nix-darwin configuration and optional Brewfile.                                                    |
| Windows  | Selected WinGet profiles and only the shared Scoop, PowerShell, fonts, or registry components declared by BYOR. |
| Linux    | The selected profile's declared apt/pacman packages and optional Home Manager flake.                            |

See [BYOR](/docs/source-configuration/) for the contract format, remote Git authentication, staged refresh, and migration from raw routes or implicit defaults.
