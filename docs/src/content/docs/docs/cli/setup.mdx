`setup` is the first-run workflow. It initializes local state, fetches declarations, and installs or activates what is missing. Native package steps never remove packages. Use [`init`](/docs/cli/init/) to prepare state without changing the machine, or [`apply`](/docs/cli/apply/) for repeatable reconciliation from the local cache.

## Usage

```bash
outfitting-manager setup
```

Native package steps do not upgrade packages that are already installed. Use [`update`](/docs/cli/update/) for upgrades. Nix activation is declarative: macOS nix-darwin and Linux Home Manager may add, replace, or remove managed packages to match their configuration.

## Source options

The exact flags depend on the compiled platform binary:

| Option                      | Purpose                                                    |
| --------------------------- | ---------------------------------------------------------- |
| `--machine-id <id>`         | Override the [machine ID](/docs/source-configuration/#machine-id). |
| `--manifest-base-url <url>` | Use a raw-compatible repository base URL.                  |
| `--manifest-ref <ref>`      | Use a branch, tag, or commit instead of `main`.            |
| `--no-fetch` (macOS/Linux)  | Use the source or manifest already cached locally.         |

## Platform differences

| Platform | What `setup` applies                                                                                                              | Platform-specific invocation                                                                       |
| -------- | --------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| macOS    | Activates the declared nix-darwin configuration and installs missing Brewfile items. Existing unrelated Homebrew packages remain. | `outfitting-manager setup`; add `--repo <path>` to use a local checkout.                           |
| Windows  | Installs missing packages from the selected WinGet and Scoop profiles and refreshes the cached PowerShell profile.                | `outfitting-manager setup --profile base,dev`; add `--winget-only` while bootstrapping WinGet.     |
| Linux    | Installs missing apt or pacman packages. Nix-backed profiles also apply Home Manager.                                             | `outfitting-manager setup --profile generic-linux`; use `--package-manager` to override detection. |
