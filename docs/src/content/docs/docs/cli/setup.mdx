`setup` validates the [configured source](/docs/source-configuration/), installs missing packages, and applies declarative configuration. Configure `[source] path` or remote `repository` and `ref` in `config.toml` first.

```bash
outfitting-manager setup
outfitting-manager --config ~/machine/config.toml setup
```

Remote sources publish a validated runtime snapshot under `source/`; `--no-refresh` reuses an existing snapshot. Local checkouts are read directly. Native package setup installs missing entries but does not upgrade or remove installed packages. Nix activation can change managed system state. Use [`init`](/docs/cli/init/) to validate without applying, [`apply`](/docs/cli/apply/) to reconcile packages, and [`update`](/docs/cli/update/) to upgrade installed software.

Linux applies the selected profile's apt/pacman and optional Nix declarations; macOS applies its Nix and optional Brewfile; Windows applies selected WinGet profiles and only declared `[windows.shared]` components.
