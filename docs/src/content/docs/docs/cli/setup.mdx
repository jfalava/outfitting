`setup` prepares the local state that later commands use. Its work is platform-specific: macOS fetches a sparse source and repairs Nix links, Windows initializes its cache and applies selected package profiles, and Linux caches the selected package profile.

## Platform commands

- [macOS setup](/docs/cli/macos/setup/) — create the state root, fetch the sparse source, and ensure Home Manager and nix-darwin links.
- [Windows setup](/docs/cli/windows/setup/) — initialize state, apply WinGet and Scoop profiles, and cache the PowerShell profile.
- [Linux setup](/docs/cli/linux/) — cache the `generic-linux` profile, or opt in to `oci-agents`.
- [WSL installation](/docs/cli/linux/install/) — run the hosted installer modes.

Use the platform page for flags, source overrides, profile selection, and collision behavior.
