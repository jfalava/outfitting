`upgrade` checks the latest GitHub release for the current platform, verifies its checksum, and replaces the installed compiled binary.

## `upgrade`

```bash
outfitting-manager upgrade
```

Run this from the installed release binary, not from Bun source. Verify the new version afterward:

```bash
outfitting-manager --version
```

## Platform differences

| Platform | Replacement behavior | Notes |
| --- | --- | --- |
| macOS | Replaces the current executable and restores its executable bit. | If macOS reports a quarantine warning, remove the browser quarantine attribute from the downloaded binary. |
| Windows | Writes a temporary `.exe` and uses a hidden PowerShell process to replace the running executable after exit. | Run a new PowerShell session before checking `outfitting-manager --version`. |
| Linux | Replaces the current executable and restores its executable bit. | The release archive is selected for Linux x64 or arm64. |
