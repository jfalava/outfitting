## WSL

Quick update:

```bash
curl -L wsl.jfa.dev | bash
```

Update local configuration after editing files in `~/.config/outfitting/repo`:

```bash
git pull
hm-sync
```

Update packages:

```bash
hm-update
update-all
```

Re-run post-install work, including the Cloudflare Access-protected licensed font installation:

```bash
curl -L mac.jfa.dev/post-install | bash
```

Other update modes:

```bash
curl -L wsl.jfa.dev | bash -s -- --update-only
curl -L wsl.jfa.dev | bash -s -- --full-install
```

## macOS

Update local configuration after editing files in `~/.config/outfitting/repo`:

```bash
git pull
outfit sync
hm-sync
```

Update packages:

```bash
outfit upgrade
hm-update
update-all
```

## Windows

Update the repository-managed configuration:

```powershell
Set-Location "$HOME\.config\outfitting\repo"
git pull
```

The main Windows installer downloads the latest checksum-verified `outfitting-manager` release to `%USERPROFILE%\.local\bin\outfitting-manager.exe`. The post-install script silently checks that same path and makes a checksum-verified, best-effort download if the binary is missing. Neither script creates a manager symlink or builds the manager from the repository.

The PowerShell profile entry points themselves remain symlinks to the repository-owned profile. Open a new PowerShell session after pulling, or reload the profile in the current session:

```powershell
. $PROFILE
```

Update packages and record the current Windows package inventories:

```powershell
Update-All
```

The inventory steps use `outfitting-manager` only when an application with that name is available on `PATH`. If it is unavailable, the affected lockfile snapshot is skipped with a warning; the rest of `Update-All` continues.

Re-run post-install work, including downloading and extracting the Cloudflare Access-protected licensed fonts to `%USERPROFILE%\Downloads\fonts` for optional manual installation:

```powershell
irm win.jfa.dev/post-install | iex
```

## Install or Update Bun Global Packages (WSL/macOS)

WSL:

```bash
curl -fsSL wsl.jfa.dev/packages/bun | xargs -I {} bun install -g {}
```

macOS:

```bash
curl -fsSL mac.jfa.dev/packages/bun | xargs -I {} bun install -g {}
```
