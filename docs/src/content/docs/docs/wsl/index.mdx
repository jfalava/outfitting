Outfitting configures Ubuntu-based Windows Subsystem for Linux distributions with Nix and Home Manager.

Start with the [installation instructions](/docs/wsl/installation/), then use the [updates](/docs/wsl/updates/) page to apply repository and package changes.

## After installation

Use Home Manager to apply configuration changes or update packages:

```bash
# Apply config changes
hm-sync

# Update packages and apply config
hm-update
```

The WSL setup is independent of the Windows host setup; use the [Windows overview](/docs/windows/) for the host installation.
