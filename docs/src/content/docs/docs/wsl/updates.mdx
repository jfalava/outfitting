For detailed command behavior, see the [Linux CLI reference](/docs/cli/linux/), especially [Home Manager](/docs/cli/linux/home-manager/) and [maintenance](/docs/cli/linux/maintenance/).

The normal local workflow is:

```bash
git -C ~/.config/outfitting/repo pull
hm-sync
```

Run `update-all` for APT, Home Manager, Nix cleanup, and Bun global packages. Run `remote-update` to invoke the hosted update-only installer.
