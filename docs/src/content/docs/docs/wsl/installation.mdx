Run the hosted installer from an interactive WSL shell:

```bash
curl -L wsl.jfa.dev | bash
```

Use `--full-install` for APT, Docker, HashiCorp tooling, Nix, and Home Manager. Use `--update-only` for the APT-only path or `--nix-only` for the Nix and Home Manager path.

See the [Linux install command](/docs/cli/linux/install/) for all accepted modes and aliases. The installer normally clones the repository to `$HOME/.config/outfitting/repo`.
