## What is this?

Outfitting is a local machine system that provides automated setup scripts, dotfiles, and Cloudflare Workers for provisioning personal development environments across Windows, WSL, and macOS.

## CLI

[CLI](/docs/cli) covers `outfitting-manager`: what it is, when [Windows](/docs/windows), [WSL](/docs/wsl), and [macOS](/docs/macos) install it, and the [provision](/docs/cli/provision), [upgrade](/docs/cli/upgrade), [lockfiles](/docs/cli/lockfiles), and [fonts](/docs/cli/fonts) commands.

## Architecture

[Architecture](/docs/architecture) covers how the pieces fit: the [API](/docs/architecture/api), [router](/docs/architecture/router), and [installer](/docs/architecture/installer) workers, [CLI internals](/docs/architecture/cli), and [dotfiles and machine state](/docs/architecture/dotfiles).

## Quick Start

1. Run your platform installer command from [Windows](/docs/windows), [WSL](/docs/wsl), or [macOS](/docs/macos).
2. Use the platform-specific [Windows updates](/docs/windows/updates), [WSL updates](/docs/wsl/updates), or [macOS updates](/docs/macos/updates) page for ongoing maintenance.
