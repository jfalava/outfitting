## What is this?

Outfitting is a local machine system that provides automated setup scripts, dotfiles, and Cloudflare Workers for provisioning personal development environments across Windows, Linux, and macOS.

## CLI

The CLI section in the sidebar lists every command. Start with [macOS](/docs/cli/macos/), [Windows](/docs/cli/windows/), or [Linux](/docs/cli/linux/), or open [init](/docs/cli/init/), [setup](/docs/cli/setup/), [apply](/docs/cli/apply/), [sync](/docs/cli/sync/), [update](/docs/cli/update/), or [status](/docs/cli/status/) directly.

## Architecture

[Architecture](/docs/architecture) covers how the pieces fit: the [API](/docs/architecture/api), router, and installer workers, CLI internals, and [dotfiles and machine state](/docs/architecture/dotfiles).

## Quick Start

1. Run your platform installer from [Windows](/docs/windows/installation/), [Linux](/docs/linux/installation/), or [macOS](/docs/macos/installation/).
2. Use [Windows updates](/docs/windows/updates), [Linux updates](/docs/linux/updates), or [macOS updates](/docs/macos/updates) for ongoing maintenance.
