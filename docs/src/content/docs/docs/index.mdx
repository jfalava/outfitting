## What is this?

Outfitting is a local machine system that provides automated setup scripts, dotfiles, and Cloudflare Workers for provisioning personal development environments across Windows, WSL, and macOS.

## CLI

[Platform CLI references](/docs/cli/macos/) document the commands available on [macOS](/docs/cli/macos/), [Windows](/docs/cli/windows/), and [Linux/WSL](/docs/cli/linux/). Shared `outfitting-manager` commands are documented under [provision](/docs/cli/provision/), [upgrade](/docs/cli/upgrade/), [lockfiles](/docs/cli/lockfiles/), and [fonts](/docs/cli/fonts/).

## Architecture

[Architecture](/docs/architecture) covers how the pieces fit: the [API](/docs/architecture/api), router, and installer workers, CLI internals, and [dotfiles and machine state](/docs/architecture/dotfiles).

## Quick Start

1. Run your platform installer command from [Windows](/docs/windows), [WSL](/docs/wsl), or [macOS](/docs/macos).
2. Use the platform-specific [Windows updates](/docs/windows/updates), [WSL updates](/docs/wsl/updates), or [macOS updates](/docs/macos/updates) page for ongoing maintenance.
