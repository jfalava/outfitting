Desired state lives in the repo; machine-local operations and locks are pushed to the API worker. Platform install and maintenance pages cover the steps — this page maps the pieces.

## Dotfiles

- `dotfiles/Microsoft.PowerShell_profile.ps1` — Windows shell: `PATH` and the `outfit` alias for `outfitting-manager`.
- `dotfiles/.gitconfig` — identity, SSH commit/tag signing.
- `dotfiles/ssh.config` — GitHub SSH defaults.

Installers symlink the profile entry points (Windows backs up existing profiles with a timestamp); Apple Silicon, WSL, and NixOS machines link the nix-darwin / Home Manager sources instead.

## System definitions

- `system/macos/` (`darwin.nix`, `home.nix`, `flake.nix`, `zsh/macos.plugin.zsh`) — canonical `outfit update nix|brew|bun|all` commands, Nix `build|switch|test|dry` actions, Homebrew reconcile, remote Nix lock pull/push, and recovery checkpoint under XDG state.
- `system/ubuntu-wsl/` (`base.nix`, `flake.nix`, `zsh/wsl.plugin.zsh`) — `hm-sync|switch|update`, `update-all`, `remote-update` from `wsl.jfa.dev`.
- `system/nixos/` (`configuration.nix`, `desktop.nix`, `server.nix`, `home.nix`, `flake.nix`) — host roles.
- `system/windows/registry/*.reg` — machine tweaks (Recall, Copilot, Ink, developer mode, menu delay).
- `system/common/` (`zsh.nix`, `zsh/outfitting.plugin.zsh`) — shared shell setup.

## Package manifests

Committed desired state: `packages/macos/` (Brewfile, nix), `packages/windows/` (`base`, `dev`, `work`, `gaming`, `qol`, `network`, `scoop.txt`, `pwsh-modules.txt`, `msstore-*`), `packages/ubuntu-wsl/` (`apt.txt`, `packages.nix`), `packages/common/`, `packages/bun.txt`. Windows clients fetch selected files from GitHub and keep the unified `windows.lock.json` outside the checkout.

## Fonts

`fonts/fontget.txt` lists the 16 public FontGet entries installed by post-install. Licensed fonts ship separately as R2 `releases/fonts.tar.gz` — see [CLI fonts](/docs/cli/fonts).

## Install and reconcile

Root `*-install-script.{sh,ps1}` files are served live from the installer hosts. Windows bootstraps the checksum-verified `outfitting-manager` release, fetches the selected manifests and PowerShell profile sparsely from GitHub, and symlinks profile entry points to the cached profile. Registry/OpenSSH setup remains PowerShell; post-install adds Scoop and fonts (with package installs delegated to the CLI).

Day-to-day Windows reconciliation uses `outfit sync` and uploads `windows.lock.json` (`<username>:x86_64-windows`). Direct remote transport is available under `outfit lockfiles`. macOS continues to use `nix` plus `homebrew-inventory` (`jfalava:aarch64-darwin`).
