Outfitting manages an Apple Silicon macOS development environment with Homebrew, Nix, nix-darwin, Home Manager, and the repository's inventory tools.

Start with the [installation instructions](/docs/macos/installation/) to bootstrap the machine, then use the [post-install steps](/docs/macos/post-install/) and [updates](/docs/macos/updates/) as needed.

## Everyday commands

The macOS Zsh profile provides the `outfit` command, also available as `o`:

```bash
# Apply the Homebrew manifest, remove unlisted casks, and store an inventory
outfit sync

# Upgrade nix-darwin, Homebrew packages/casks, and store an inventory
outfit upgrade

# Preview, build, test, or apply Nix-darwin changes
outfit dry
outfit build
outfit test
outfit switch
```

Successful `outfit sync` and `outfit upgrade` operations store a versioned inventory of Homebrew taps, formulae, and casks through `outfitting-manager`. The inventory is observed state; the committed Brewfile remains the desired Homebrew configuration.

Store the observed Homebrew inventory without changing packages:

```bash
outfit snapshot
```

If an upgrade is interrupted after creating a candidate Nix lock, Outfitting keeps a recovery checkpoint under the XDG state directory, by default `$HOME/.local/state/outfitting/nix-lock-recovery`. Resume it with:

```bash
outfit recover
```

## Nix-darwin profile management

```bash
# Repair profile symlinks and apply the local repository configuration
hm-sync

# List and roll back generations
hm-rollback
```

Use the `outfit` wrappers rather than invoking `darwin-rebuild` directly. They retrieve the canonical remote lock and prevent Nix from creating a repository `flake.lock`.

## Nix package testing

```bash
nix-test bat
nix-try ripgrep
```
