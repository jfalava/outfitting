Outfitting manages an Apple Silicon macOS development environment with Homebrew, Nix, nix-darwin, Home Manager, and the repository's inventory tools.

Start with the [installation instructions](/docs/macos/installation/) to bootstrap the machine, then use the [post-install steps](/docs/macos/post-install/) and [updates](/docs/macos/updates/) as needed.

## Everyday commands

The macOS Zsh profile provides the `outfit` command, also available as `o`. Package updates use `outfit update <origin> [action]`:

```bash
# Apply and upgrade the Homebrew desired state
outfit update brew

# Update all package origins: Nix, Homebrew, then Bun
outfit update all

# Update Nix-darwin (switch is the default action)
outfit update nix

# Build, test, preview, or apply Nix-darwin changes
outfit update nix build
outfit update nix test
outfit update nix dry
outfit update nix switch

# Update global Bun packages
outfit update bun
```

Successful Homebrew updates store a versioned inventory of taps, formulae, and casks through `outfitting-manager`. The inventory is observed state; the committed Brewfile remains the desired Homebrew configuration.

The Zsh profile keeps Nix compatibility shortcuts and a native Nix fallback when `outfitting-manager` is unavailable. Homebrew, Bun, aggregate updates, snapshots, and setup are manager-owned and require `outfitting-manager`.

Capture the observed Homebrew state without reconciling packages:

```bash
outfit snapshot brew
```

If an update is interrupted after creating a candidate Nix lock, Outfitting keeps a recovery checkpoint under the XDG state directory, by default `$HOME/.local/state/outfitting/nix-lock-recovery`. Resume it with:

```bash
outfit recover nix
```

## Nix-darwin profile management

```bash
# Repair profile symlinks and apply the local repository configuration
hm-sync

# List and roll back generations
hm-rollback
```

Use the `outfit` wrappers rather than invoking `darwin-rebuild` directly. They retrieve the canonical remote lock and prevent Nix from creating a repository `flake.lock`.

## Nix package testing

```bash
nix-test bat
nix-try ripgrep
```
