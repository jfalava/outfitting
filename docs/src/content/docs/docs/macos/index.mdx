Outfitting manages an Apple Silicon macOS development environment with Homebrew, Nix, nix-darwin, Home Manager, and the repository's inventory tools.

Start with [installation](/docs/macos/installation/), run the [post-install steps](/docs/macos/post-install/) when needed, and use [updates](/docs/macos/updates/) for the normal maintenance workflow.

The complete manager command tree and Zsh compatibility helpers are in the [macOS CLI reference](/docs/cli/macos/).
