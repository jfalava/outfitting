## Prerequisites

- **Hardware:** Apple Silicon Mac (M1/M2/M3/M4).
- **Permissions:** An interactive terminal session with `sudo` access.
- **Network:** Internet access to GitHub, Homebrew, and Determinate Systems (Nix installer).

## Install

Run the hosted installer script:

```bash
curl -L mac.jfa.dev | bash
```

> [!WARNING]
> The bootstrap runs `init`, `nix switch`, and `apply` directly. Configure `config.toml` with the selected profile and source before running the installer.

## Configure a source

Configure `[source] path` or remote `repository` and `ref`, plus `[macos] profile`, in the machine-local [config.toml](/docs/source-configuration/).

```bash
outfitting-manager init
outfitting-manager validate # optional check of the fetched source
outfitting-manager nix switch
outfitting-manager apply
```

GitHub, GitHub Enterprise, HTTPS Git, and SSH remotes are supported. `apply` reconciles the Brewfile; Nix activation is separate. See [macOS configuration](/docs/source-configuration/byor/macos/) for Nix, Brewfile, and font declarations.

For macOS commands and shell helpers, see the [macOS CLI reference](/docs/cli/macos/).
