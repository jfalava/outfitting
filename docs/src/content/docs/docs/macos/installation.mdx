## Prerequisites

- **Hardware:** Apple Silicon Mac (M1/M2/M3/M4).
- **Permissions:** An interactive terminal session with `sudo` access.
- **Network:** Internet access to GitHub, Homebrew, and Determinate Systems (Nix installer).

## Install

Run the hosted installer script:

```bash
curl -L mac.jfa.dev | bash
```

> [!WARNING]
> The current bootstrap may still invoke an older source flow. Configure `config.toml` before running manager setup manually.

## Configure a source

Configure `[source] path` or remote `repository` and `ref`, plus `[macos] profile`, in the machine-local [config.toml](/docs/source-configuration/).

```bash
outfitting-manager validate
outfitting-manager setup
```

GitHub, GitHub Enterprise, HTTPS Git, and SSH remotes are supported. See [macOS configuration](/docs/source-configuration/byor/macos/) for Nix, Brewfile, and font declarations.

For macOS commands and shell helpers, see the [macOS CLI reference](/docs/cli/macos/).
