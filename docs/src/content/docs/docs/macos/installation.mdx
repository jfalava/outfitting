## Prerequisites

- Apple Silicon macOS.
- An interactive terminal and an account that can use `sudo`.
- Network access to GitHub, Homebrew, Determinate Systems, and the Outfitting lockfile service.

## Install

```bash
curl -L mac.jfa.dev | bash
```

Open a new shell after installation. See [setup](/docs/cli/setup/) for state-source options and [update](/docs/cli/update/) for ongoing maintenance.

## BYOR (Bring Your Own Repo)

You can use a compatible repository instead of the default Outfitting source.

### Local contract (`outfitting.json`)

Point the manager at a checkout that declares a macOS profile, then validate and apply:

```bash
outfitting-manager validate --repo ~/src/my-machine-config --platform macos
outfitting-manager setup --repo ~/src/my-machine-config
```

See [BYOR for macOS](/docs/source-configuration/byor/macos/) for the contract schema, optional Brewfile/fonts paths, and profile selection.

### Hosted sparse source

For a hosted repository without a local checkout, provide its raw-content base URL and Git ref:

```bash
outfitting-manager setup \
  --manifest-base-url https://raw.githubusercontent.com/example/my-machine-config \
  --manifest-ref main
```

Hosted sources still use the legacy fixed macOS path closure (`system/macos/*`, `packages/macos/Brewfile`, and so on). The flake must expose `darwinConfigurations`. Setup validates the source before activating Nix or applying Homebrew state.

The complete manager command tree and Zsh compatibility helpers are in the [macOS CLI reference](/docs/cli/macos/).
