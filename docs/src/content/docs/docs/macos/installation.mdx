## Prerequisites

- **Hardware:** Apple Silicon Mac (M1/M2/M3/M4).
- **Permissions:** An interactive terminal session with `sudo` access.
- **Network:** Internet access to GitHub, Homebrew, and Determinate Systems (Nix installer).

## Install

Run the hosted installer script:

```bash
curl -L mac.jfa.dev | bash
```

> [!WARNING]
> The current bootstrap still invokes `init` and `setup` without an explicit BYOR source. Those manager steps cannot complete until the installer is migrated. Installer scripts are unchanged by this migration.

## Configure a source

The manager accepts either a local checkout with a root `outfitting.json` or a remote Git source explicitly declared in the state-root `byor.json`. It does not infer a repository, profile layout, or default ref.

For a local checkout:

```bash
outfitting-manager validate --repo ~/src/my-machine-config --platform macos
outfitting-manager setup --repo ~/src/my-machine-config --profile personal-mac
```

For a remote Git source, use [`outfitting-manager byor`](/docs/cli/byor/) to select the repository, ref, profile, and paths:

```bash
outfitting-manager byor
outfitting-manager setup --profile personal-mac
```

GitHub, GitHub Enterprise, HTTPS Git, and SSH remotes are supported. See [BYOR for macOS](/docs/source-configuration/byor/macos/) for the contract, Brewfile paths, and fonts.

For macOS commands and shell helpers, see the [macOS CLI reference](/docs/cli/macos/).
