## Prerequisites

- Apple Silicon macOS.
- An interactive terminal and an account that can use `sudo`.
- Network access to GitHub, Homebrew, Determinate Systems, and the Outfitting lockfile service.

## Install

```bash
curl -L mac.jfa.dev | bash
```

Open a new shell after installation. See [setup](/docs/cli/setup/) for state-source options and [update](/docs/cli/update/) for ongoing maintenance.

## BYOR (Bring Your Own Repo)

You can use a compatible repository instead of the default Outfitting source. For a local checkout, pass its path to setup:

```bash
outfitting-manager setup --repo ~/src/my-machine-config
```

For a hosted repository, provide its raw-content base URL and Git ref:

```bash
outfitting-manager setup \
  --manifest-base-url https://raw.githubusercontent.com/example/my-machine-config \
  --manifest-ref main
```

The repository must include the macOS source closure: `system/macos/flake.nix`, `system/macos/darwin.nix`, `system/macos/home.nix`, the shared modules and package files, and `packages/macos/Brewfile`. The flake must expose `darwinConfigurations`. Setup validates the source before activating Nix or applying Homebrew state.

The complete manager command tree and Zsh compatibility helpers are in the [macOS CLI reference](/docs/cli/macos/).
