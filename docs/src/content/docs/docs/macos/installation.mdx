## Prerequisites

- **Hardware:** Apple Silicon Mac (M1/M2/M3/M4).
- **Permissions:** An interactive terminal session with `sudo` access.
- **Network:** Internet access to GitHub, Homebrew, Determinate Systems (Nix installer), and the Outfitting lockfile service.

## Install

Run the hosted installer script:

```bash
curl -L mac.jfa.dev | bash
```

Once the installation finishes, open a new shell session to load updated environment variables.

## Bring Your Own Repo (BYOR)

You can use your own dotfiles repository instead of Outfitting's built-in configuration.

### Custom repository (`outfitting.json`)

If your repository has an `outfitting.json` file defining a macOS profile, point `outfitting-manager` to your local clone:

```bash
# Validate the configuration without making changes
outfitting-manager validate --repo ~/src/my-machine-config --platform macos

# Apply nix-darwin and Homebrew configuration
outfitting-manager setup --repo ~/src/my-machine-config
```

See [BYOR for macOS](/docs/source-configuration/byor/macos/) for configuration options, Brewfile paths, and font manifests.

### Hosted remote repository

If you prefer to pull directly from a hosted Git repository without keeping a local clone, pass the raw URL and branch:

```bash
outfitting-manager setup \
  --manifest-base-url https://raw.githubusercontent.com/example/my-machine-config \
  --manifest-ref main
```

Hosted sources expect Outfitting's default macOS directory structure (e.g., `system/macos/flake.nix`, `packages/macos/Brewfile`), and the Nix flake must expose `darwinConfigurations`.

For the full list of macOS commands and shell helpers, see the [macOS CLI reference](/docs/cli/macos/).
