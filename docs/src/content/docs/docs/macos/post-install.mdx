Run the post-install script from a new shell:

```bash
curl -L mac.jfa.dev/post-install | bash
```

### What gets configured

1. **Public fonts:** Installs the open-source font collection using FontGet.
2. **Licensed fonts (optional):** Authenticates via Cloudflare Access, verifies the archive download, and installs licensed fonts to `/Library/Fonts`.

### Requirements

- `sudo` access to install fonts system-wide into `/Library/Fonts`.
- Homebrew and FontGet (both configured during initial install).
- Cloudflare Access authorization to access the private font archive.

To manage or publish licensed fonts as an administrator, see [CLI fonts](/docs/cli/fonts/).
