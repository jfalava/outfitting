Run the post-install script from a new shell:

```bash
curl -L mac.jfa.dev/post-install | bash
```

It installs the public FontGet list from the sparse source, authenticates for the protected licensed archive, validates the download, and installs verified fonts under `/Library/Fonts`.

The script requires FontGet, Homebrew, Cloudflare Access authorization, and `sudo`. It is strict: missing lists, failed downloads, checksum mismatches, unsafe archives, and installation failures return a non-zero status.

Operators publish the licensed archive with [CLI fonts](/docs/cli/fonts/).
