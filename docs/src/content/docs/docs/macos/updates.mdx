## Repository-managed configuration

The installer stores the checkout path in `$HOME/.config/outfitting/repo-path` and protects that file with mode 600. Pull the latest repository changes from the configured checkout:

```bash
repo_path="$(cat "$HOME/.config/outfitting/repo-path")"
git -C "$repo_path" pull --ff-only
```

Apply updated Nix-darwin/Home Manager configuration and repair its symlinks:

```bash
hm-sync
```

Apply and upgrade the committed Homebrew manifest, remove unlisted casks, and store the observed Homebrew inventory:

```bash
outfit update brew
```

If you only need to pull repository changes without applying package managers, use the repository update commands above and leave activation for a later `outfit update nix switch`.

## Packages and inventories

Use the origin-specific commands when you want one package manager, or the aggregate command for the normal combined update:

```bash
outfit update nix
outfit update brew
outfit update bun
outfit update all
```

`outfit update nix` builds and activates nix-darwin using the canonical remote lock. `outfit update brew` reconciles and upgrades Homebrew, then stores the observed inventory. `outfit update bun` updates global Bun packages. `outfit update all` runs Nix, Homebrew, and Bun in order, continues after individual failures, and returns a failure if any step fails.

The Zsh profile keeps the previous `outfit sync`, `outfit upgrade`, and update helper functions as compatibility paths. If the manager binary is unavailable, `outfit update nix|brew|bun|all` falls back to native shell operations; remote inventory synchronization is only available through the manager.

The standalone snapshot helper remains a compatibility surface while the manager-owned command is migrated. A successful `outfit update brew` already stores the current Homebrew state:

```bash
outfit snapshot
```

## Individual operations

```bash
# Nix-darwin configuration only
outfit update nix switch

# Preview, build, test, or apply Nix-darwin changes
outfit update nix dry
outfit update nix build
outfit update nix test
outfit update nix switch

# Remove old Nix generations and store paths
hm-clean

# Update global Bun packages manually
outfit update bun
```

Use the Zsh profile functions after opening a new shell or reloading the profile. The outfit commands use the canonical `jfalava:aarch64-darwin/nix` lock and do not create a repository `flake.lock`.

## Post-install work

Run the [post-install steps](/docs/macos/post-install/) to install public fonts and licensed fonts system-wide:

```bash
curl -L mac.jfa.dev/post-install | bash
```
