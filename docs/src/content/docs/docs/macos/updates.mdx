For command details, see [setup](/docs/cli/setup/), [update](/docs/cli/update/), [snapshot](/docs/cli/macos/snapshot/), [recover](/docs/cli/macos/recover/), and [shell helpers](/docs/cli/macos/shell/).

The usual maintenance sequence is:

```bash
outfitting-manager setup
outfitting-manager update all
bun update -g
```

Use `outfitting-manager snapshot brew` to record observed Homebrew state without reconciling packages, and `outfitting-manager recover nix` after an interrupted Nix operation. Run the [post-install script](/docs/macos/post-install/) separately when fonts need refreshing.
