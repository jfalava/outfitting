The macOS manager stores its configuration, cached declarations, and managed source under `~/.config/outfitting`. You can set `OUTFITTING_STATE_ROOT` to choose a different directory.

## Update Nix and Homebrew (`update`)

Use `update all` to rebuild and switch your nix-darwin configuration and upgrade installed Homebrew packages in one command:

```bash
# Update nix-darwin and Homebrew packages
outfitting-manager update all

# Update without pulling remote source changes
outfitting-manager update all --no-refresh

# Update without pushing lockfile state
outfitting-manager update all --no-push
```

`update all` continues through individual step failures and exits with a non-zero code if any step fails.

### Targeted updates

To update only nix-darwin or Homebrew:

```bash
# Nix-darwin actions: build, test, dry, or switch
outfitting-manager update nix switch
outfitting-manager update nix switch --no-refresh

# Upgrade Homebrew packages
outfitting-manager update brew
outfitting-manager update brew --no-push
```

> [!NOTE]
> `update brew` upgrades installed Homebrew formulas and casks and records the observed inventory. It does not install newly declared packages from your Brewfile (use [`setup`](/docs/cli/setup/) to install missing declarations).

## Additional tools

- **Capture Homebrew inventory:** Run [snapshot](/docs/cli/macos/snapshot/) to record installed Homebrew packages to the lockfile without running upgrades.
- **Recover Nix:** Run [recover](/docs/cli/macos/recover/) if a previous nix-darwin build or switch operation was interrupted.
- **Update Outfitting CLI:** Run `outfitting-manager upgrade` to update the manager binary itself.

For the full command list, see the [macOS CLI reference](/docs/cli/macos/).
