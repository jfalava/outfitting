The macOS manager stores its configuration, cached declarations, and managed source under `~/.config/outfitting`. You can set `OUTFITTING_STATE_ROOT` to choose a different directory.

## Activate nix-darwin (`nix`)

Nix actions are separate from native package updates. Use [`nix`](/docs/cli/nix/) to build or activate the configured nix-darwin profile:

```bash
outfitting-manager nix build
outfitting-manager nix switch
outfitting-manager nix switch --no-refresh
outfitting-manager nix switch --no-push
```

`switch` builds and activates nix-darwin. `--no-refresh` uses the validated local source; `--no-push` keeps lock changes local.

## Reconcile or upgrade Homebrew packages

Use [`apply`](/docs/cli/apply/) to install missing Brewfile entries and [`update`](/docs/cli/update/) to upgrade installed formulas and casks:

```bash
outfitting-manager apply
outfitting-manager update
outfitting-manager update --no-push
```

> [!NOTE]
> `update` upgrades installed Homebrew formulas and casks and records the observed inventory. It does not install newly declared packages from your Brewfile; use `apply` for that. There is no combined command: run the Nix and Homebrew actions you intend explicitly.

## Additional tools

- **Capture Homebrew inventory:** Run [snapshot](/docs/cli/macos/snapshot/) to record installed Homebrew packages to the lockfile without running upgrades.
- **Recover Nix:** Run [recover](/docs/cli/macos/recover/) if a previous nix-darwin build or switch operation was interrupted.
- **Update Outfitting CLI:** Run [`self-update`](/docs/cli/self-update/) to update the manager binary itself.

For the full command list, see the [macOS CLI reference](/docs/cli/macos/).
