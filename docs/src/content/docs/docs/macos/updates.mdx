For the command details, see the [macOS CLI reference](/docs/cli/macos/), especially [setup](/docs/cli/macos/setup/), [update](/docs/cli/macos/update/), [snapshot](/docs/cli/macos/snapshot/), [recover](/docs/cli/macos/recover/), and [shell helpers](/docs/cli/macos/shell/).

The usual maintenance sequence is:

```bash
outfit setup
outfit update all
bun update -g
```

Use `outfit snapshot brew` to record observed Homebrew state without reconciling packages, and `outfit recover nix` after an interrupted Nix operation. Run the [post-install script](/docs/macos/post-install/) separately when fonts need refreshing.
