## Configuration source

The installer stores the sparse source path in `$HOME/.config/outfitting/repo-path` and protects that file with mode 600. Nix updates refresh the source automatically; refresh it without activating with:

```bash
outfit setup
```

Apply updated Nix-darwin/Home Manager configuration and repair its symlinks:

```bash
hm-sync
```

Apply and upgrade the committed Homebrew manifest, remove unlisted casks, and store the observed Homebrew inventory:

```bash
outfit update brew
```

If you only need to refresh the sparse source without applying package managers, run `outfit setup` and leave activation for a later `outfit update nix switch`.

## Packages and inventories

Use the origin-specific commands when you want one package manager, or the aggregate command for the normal combined update:

```bash
outfit update nix
outfit update brew
outfit update all
```

`outfit update nix` builds and activates nix-darwin using the canonical remote lock. `outfit update brew` reconciles and upgrades Homebrew, then stores the observed inventory. `outfit update all` runs Nix and Homebrew in order, continues after individual failures, and returns a failure if any step fails. Update global Bun packages with `bun update -g`.

The Zsh profile defines `outfit` and `o` as direct aliases for `outfitting-manager`; it keeps only Nix compatibility helpers and a native Nix fallback for those helpers. Homebrew, Bun, aggregate updates, snapshots, and setup are manager-owned; if the manager binary is unavailable, those operations fail without running native shell updates.

Capture only the current Homebrew state with:

```bash
outfit snapshot brew
```

If Nix activation or lock publication is interrupted, resume the durable checkpoint with:

```bash
outfit recover nix
```

## Individual operations

```bash
# Nix-darwin configuration only
outfit update nix switch

# Preview, build, test, or apply Nix-darwin changes
outfit update nix dry
outfit update nix build
outfit update nix test
outfit update nix switch

# Remove old Nix generations and store paths
hm-clean

# Update global Bun packages with Bun itself
bun update -g
```

Use the Zsh profile functions after opening a new shell or reloading the profile. The outfit commands use the canonical `jfalava:aarch64-darwin/nix` lock and do not create a repository `flake.lock`.

## Post-install work

Run the [post-install steps](/docs/macos/post-install/) to install public fonts and licensed fonts system-wide:

```bash
curl -L mac.jfa.dev/post-install | bash
```
