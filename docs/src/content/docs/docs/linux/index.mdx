Outfitting manages a Linux development environment with the compiled `outfitting-manager`, native packages (apt or pacman), and optional Home Manager configuration.

Start with [installation](/docs/linux/installation/) and use [updates](/docs/linux/updates/) for day-to-day maintenance.

Command details live in the [Linux CLI reference](/docs/cli/linux/).
