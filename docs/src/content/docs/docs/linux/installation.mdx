## Prerequisites

- An interactive shell and an account that can use `sudo` when the package manager needs it.
- Network access to GitHub and the Outfitting release assets.

## Install

```bash
curl -L linux.jfa.dev | bash
```

The installer will detect the package manager of your distro. State lives under `~/.config/outfitting`.

> Only APT-based and pacman-based distros are supported for now.

## Profiles

By default you get the portable package list. Other profiles select a different package manifest and, when present, a Home Manager flake:

| Profile         | Role                                                                   |
| --------------- | ---------------------------------------------------------------------- |
| `generic-linux` | Default. Native packages only (apt or pacman).                         |
| `ubuntu-wsl`    | Ubuntu package set plus Home Manager under `system/ubuntu-wsl`.        |
| `oci-agents`    | Headless host package set plus Home Manager under `system/oci-agents`. |

```bash
curl -L linux.jfa.dev | bash -s -- --profile generic-linux
```

You can also set the profile later:

```bash
outfitting-manager init --profile oci-agents
outfitting-manager setup --no-fetch
```

## BYOR (Bring Your Own Repo)

You can use a compatible repository instead of the default Outfitting source. For a local checkout, select a profile and pass its path to setup:

```bash
outfitting-manager setup \
  --profile generic-linux \
  --repo ~/src/my-machine-config
```

For a hosted repository, provide its raw-content base URL and Git ref:

```bash
outfitting-manager setup \
  --profile generic-linux \
  --manifest-base-url https://raw.githubusercontent.com/example/my-machine-config \
  --manifest-ref main
```

Use `--profile oci-agents` or `--profile ubuntu-wsl` when the repository provides that Home Manager configuration. The repository must include the selected profile's package manifest; Nix-backed profiles also require their profile flake, lockfile, Home Manager files, shared modules, and bootstrap files. Setup validates and selects the source before applying packages or Home Manager state.

For command-level workflows, see [init](/docs/cli/init/), [setup](/docs/cli/setup/), and the [Linux CLI reference](/docs/cli/linux/).
