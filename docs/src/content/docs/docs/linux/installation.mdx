## Prerequisites

- An interactive terminal and an account with `sudo` privileges.
- Network access to Git and Outfitting release assets.

## Install

The hosted Linux bootstrap installs `outfitting-manager`:

```bash
curl -L linux.jfa.dev | bash
```

The script detects `apt` or `pacman`. Manager state is stored under `~/.config/outfitting`.

> [!WARNING]
> The bootstrap runs `init`, `apply`, and `nix switch` directly. Configure `config.toml` with the selected profile and source before running the installer.

## Configure a source

Declare `[source] path` or remote `repository` and `ref`, plus `[linux] profile`, in the machine-local [config.toml](/docs/source-configuration/). There are no built-in Linux profiles.

```bash
outfitting-manager init
outfitting-manager validate # optional check of the fetched source
outfitting-manager apply
```

If the selected profile declares a Nix flake, activate it separately with `outfitting-manager nix switch`. See [Linux configuration](/docs/source-configuration/byor/linux/) for profile examples. For command workflows, see [init](/docs/cli/init/), [apply](/docs/cli/apply/), [Nix](/docs/cli/nix/), [validate](/docs/cli/validate/), and the [Linux CLI reference](/docs/cli/linux/).
