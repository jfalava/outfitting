## Prerequisites

- An interactive terminal and an account with `sudo` privileges.
- Network access to Git and Outfitting release assets.

## Install

The hosted Linux bootstrap installs `outfitting-manager`:

```bash
curl -L linux.jfa.dev | bash
```

The script detects `apt` or `pacman`. Manager state is stored under `~/.config/outfitting`.

> [!WARNING]
> The bootstrap still invokes the manager's retired implicit-source flow. The BYOR-only manager cannot complete package setup through this script until the installer is migrated. Installer scripts are unchanged by this migration.

## Configure a source

The manager accepts either a local checkout with a root `outfitting.json` or a remote Git source explicitly declared in the state-root `byor.json`. It does not provide built-in Linux profiles.

For a local checkout:

```bash
outfitting-manager validate --repo ~/src/my-machine-config --platform linux
outfitting-manager setup --repo ~/src/my-machine-config --profile workstation
```

For a remote repository, configure its source map with [`byor`](/docs/cli/byor/), then select one of its declared Linux profiles:

```bash
outfitting-manager byor
outfitting-manager setup --profile workstation
```

See [BYOR for Linux](/docs/source-configuration/byor/linux/) for arbitrary contract paths and profile examples. For command workflows, see [init](/docs/cli/init/), [setup](/docs/cli/setup/), [validate](/docs/cli/validate/), and the [Linux CLI reference](/docs/cli/linux/).
