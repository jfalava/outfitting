## Prerequisites

- An interactive shell and an account that can use `sudo` when the package manager needs it.
- Network access to GitHub and the Outfitting release assets.

## Install

```bash
curl -L linux.jfa.dev | bash
```

The installer will detect the package manager of your distro. State lives under `~/.config/outfitting`.

> Only APT-based and pacman-based distros are supported for now.

## Profiles

By default you get the portable package list. Other built-in profiles select a different package manifest and, when present, a Home Manager flake:

| Profile         | Role                                                                   |
| --------------- | ---------------------------------------------------------------------- |
| `generic-linux` | Default. Native packages only (apt or pacman).                         |
| `ubuntu-wsl`    | Ubuntu package set plus Home Manager under `system/ubuntu-wsl`.        |
| `oci-agents`    | Headless host package set plus Home Manager under `system/oci-agents`. |

```bash
curl -L linux.jfa.dev | bash -s -- --profile generic-linux
```

You can also set the profile later:

```bash
outfitting-manager init --profile oci-agents
outfitting-manager setup --no-fetch
```

## BYOR (Bring Your Own Repo)

### Local contract (`outfitting.json`)

Point the manager at a checkout that declares Linux profiles, then validate and apply without requiring Outfitting’s default layout:

```bash
outfitting-manager validate --repo ~/src/my-machine-config --platform linux
outfitting-manager setup --repo ~/src/my-machine-config --profile debian-minimal
```

Profiles may declare apt, pacman, nix, or any combination. See [BYOR for Linux](/docs/source-configuration/byor/linux/) for the contract schema and multi-platform contracts.

### Hosted sparse source

For a hosted repository without a local checkout, provide its raw-content base URL and Git ref. Hosted sources still use the built-in profile layouts (`generic-linux`, `oci-agents`, `ubuntu-wsl`):

```bash
outfitting-manager setup \
  --profile generic-linux \
  --manifest-base-url https://raw.githubusercontent.com/example/my-machine-config \
  --manifest-ref main
```

For command-level workflows, see [init](/docs/cli/init/), [setup](/docs/cli/setup/), [validate](/docs/cli/validate/), and the [Linux CLI reference](/docs/cli/linux/).
