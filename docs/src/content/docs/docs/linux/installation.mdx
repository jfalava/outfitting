## Prerequisites

- An interactive terminal and an account with `sudo` privileges.
- Network access to GitHub and Outfitting release assets.

## Install

Run the hosted installation script:

```bash
curl -L linux.jfa.dev | bash
```

The installer automatically detects your distribution's package manager (`apt` on Debian/Ubuntu, `pacman` on Arch Linux). State is stored under `~/.config/outfitting`.

> [!NOTE]
> Outfitting currently supports APT-based and pacman-based Linux distributions.

## Built-in profiles

By default, installation applies the `generic-linux` package list. You can select another built-in profile that includes a Home Manager flake:

| Profile | Description |
| --- | --- |
| `generic-linux` | Default. Native packages only (`apt` or `pacman`). |
| `ubuntu-wsl` | Ubuntu package set plus WSL Home Manager configuration (`system/ubuntu-wsl`). |
| `oci-agents` | Headless host packages plus Home Manager configuration (`system/oci-agents`). |

Select a profile during installation:

```bash
curl -L linux.jfa.dev | bash -s -- --profile ubuntu-wsl
```

Or switch profiles after installation:

```bash
outfitting-manager init --profile oci-agents
outfitting-manager setup --no-fetch
```

## Bring Your Own Repo (BYOR)

### Custom profiles (`outfitting.json`)

To use your own repository, add an `outfitting.json` file defining your profiles. You can configure APT, pacman, Nix, or any combination without adhering to Outfitting’s default layout:

```bash
# Validate the configuration
outfitting-manager validate --repo ~/src/my-machine-config --platform linux

# Apply the profile
outfitting-manager setup --repo ~/src/my-machine-config --profile debian-minimal
```

See [BYOR for Linux](/docs/source-configuration/byor/linux/) for configuration examples and multi-platform support.

### Hosted remote source

If you want to pull directly from a Git host without a local clone, provide the repository's raw-content base URL and Git branch or tag. Hosted sources use the built-in profile layouts (`generic-linux`, `oci-agents`, or `ubuntu-wsl`):

```bash
outfitting-manager setup \
  --profile generic-linux \
  --manifest-base-url https://raw.githubusercontent.com/example/my-machine-config \
  --manifest-ref main
```

For command-level workflows, see [init](/docs/cli/init/), [setup](/docs/cli/setup/), [validate](/docs/cli/validate/), and the [Linux CLI reference](/docs/cli/linux/).
