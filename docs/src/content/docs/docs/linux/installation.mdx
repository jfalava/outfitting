## Prerequisites

- An interactive terminal and an account with `sudo` privileges.
- Network access to Git and Outfitting release assets.

## Install

The hosted Linux bootstrap installs `outfitting-manager`:

```bash
curl -L linux.jfa.dev | bash
```

The script detects `apt` or `pacman`. Manager state is stored under `~/.config/outfitting`.

> [!WARNING]
> The bootstrap may still invoke an older implicit-source flow. Configure `config.toml` before running manager setup manually.

## Configure a source

Declare `[source] path` or remote `repository` and `ref`, plus `[linux] profile`, in the machine-local [config.toml](/docs/source-configuration/). There are no built-in Linux profiles.

```bash
outfitting-manager validate
outfitting-manager setup
```

See [Linux configuration](/docs/source-configuration/byor/linux/) for profile examples. For command workflows, see [init](/docs/cli/init/), [setup](/docs/cli/setup/), [validate](/docs/cli/validate/), and the [Linux CLI reference](/docs/cli/linux/).
