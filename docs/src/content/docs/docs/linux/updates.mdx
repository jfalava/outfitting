The Linux manager stores its configuration, cached manifests, and managed source under `~/.config/outfitting`. Linux activates one profile at a time; see [Profiles](/docs/source-configuration/#profiles) for selection rules.

## Apply profile packages (`apply`)

Use [`apply`](/docs/cli/apply/) to install missing packages declared by the active profile:

```bash
# Reconcile all declared packages
outfitting-manager apply all

# Use local files without pulling remote source changes
outfitting-manager apply all --no-refresh

# Apply with a specific profile
outfitting-manager apply apt --profile ubuntu-wsl

# Remove packages no longer declared in the active profile
outfitting-manager apply all --prune
```

By default, `apply` only adds missing software and never uninstalls anything. When passed `--prune`, Outfitting only removes packages that it previously installed for the active profile and that are no longer in the manifest. Manually installed packages or pre-existing system packages are never removed.

Use `--offline` to skip both repository refreshes and package-manager network calls.

## Upgrade installed packages (`update`)

Use [`update`](/docs/cli/update/) to upgrade existing packages to their newest versions:

```bash
# Upgrade all packages (native and Nix if applicable)
outfitting-manager update all

# Upgrade only native packages
outfitting-manager update apt
outfitting-manager update pacman
```

## Nix and Home Manager profiles

For Nix-backed profiles (`ubuntu-wsl` and `oci-agents`), `update all` rebuilds and switches Home Manager before upgrading native packages (`generic-linux` only manages native packages).

To run targeted Home Manager actions:

```bash
outfitting-manager update nix build
outfitting-manager update nix switch
outfitting-manager update nix switch --no-refresh
```

Nix operations read the profile's `flake.lock` and refresh the managed source by default. Use `--no-refresh` to use the local checkout and `--no-push` to keep lockfile changes local.

## Additional tools

- **Manager CLI:** Run `outfitting-manager upgrade` to update the manager binary.
- **Bun packages:** Run `bun update -g` to update global Bun packages.
- **Shell helpers:** See [Home Manager](/docs/cli/linux/home-manager/) for `hm-*` aliases.

For the full command list, see the [Linux CLI reference](/docs/cli/linux/).
