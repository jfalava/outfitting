Use [apply](/docs/cli/apply/) to install missing packages from the active local profile. It preserves manually installed packages unless `--prune` can prove that Outfitting installed them for the active profile and they are no longer declared.

```bash
outfitting-manager apply all --refresh
outfitting-manager apply apt --profile ubuntu-wsl
outfitting-manager apply all --prune
```

Use [update](/docs/cli/update/) to upgrade packages that are already installed:

```bash
outfitting-manager update all
outfitting-manager update apt
outfitting-manager update pacman --offline
```

For Nix-backed profiles, `update all` refreshes and switches Home Manager before upgrading native packages. `generic-linux` remains native-only. Use `update nix` for a targeted Home Manager action:

```bash
outfitting-manager update all
outfitting-manager update all --no-refresh
outfitting-manager update nix build
outfitting-manager update nix switch --no-refresh
```

See [Home Manager](/docs/cli/linux/home-manager/) for the `hm-*` shell helpers. Update global Bun packages with `bun update -g`, and update the manager binary with `outfitting-manager upgrade`.
