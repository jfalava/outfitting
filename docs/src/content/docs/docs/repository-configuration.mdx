Each platform uses a different source layout. macOS and Linux use the manager's state root and fetch only the files needed by their platform source bundle; Windows uses cached manifests.

## Windows

Windows stores configuration and fetched manifests under:

```text
%USERPROFILE%\.config\outfitting
```

`config.json` records the manifest source and repository-relative Windows routes. `manifests` contains the selected WinGet files, the configured Scoop manifest, and the cached PowerShell profile. Windows package reconciliation does not require a monorepo checkout.

The installer links these PowerShell profile entry points to the cached profile:

```text
%USERPROFILE%\Documents\PowerShell\Microsoft.PowerShell_profile.ps1
%USERPROFILE%\Documents\PowerShell\Microsoft.VSCode_profile.ps1
%USERPROFILE%\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1
    -> %USERPROFILE%\.config\outfitting\manifests\<configured PowerShell route>
```

Existing profiles are backed up with a timestamp before they are replaced. Windows symbolic links require Developer Mode or an elevated installer session.

## macOS

```text
~/.config/outfitting/repo-path -> ~/.config/outfitting/source
~/.config/home-manager -> ~/.config/outfitting/source/system/macos
~/.nixpkgs/darwin-configuration.nix -> ~/.config/outfitting/source/system/macos/darwin.nix
```

The macOS manager fetches the allowlisted source paths into `~/.config/outfitting/source`; it does not clone the monorepo. `outfit init` validates the source before `outfit setup` applies it. A compatible repository must provide `system/macos/flake.nix`, `system/macos/darwin.nix`, and `packages/macos/Brewfile`; the flake must expose `darwinConfigurations`. Homebrew uses the local `packages/macos/Brewfile` during setup.

## Linux

Linux keeps a profile-scoped sparse source at:

```text
~/.config/outfitting/source
```

The bundle contains common modules and dotfiles, the selected profile’s package manifest, and (for Nix-backed profiles) the flake, lockfile, bootstrap, and Zsh plugin. A user-supplied `--repo` can select a full checkout instead.

Home Manager links (Nix-backed profiles):

```text
~/.config/home-manager -> ~/.config/outfitting/source/system/ubuntu-wsl
~/.config/home-manager -> ~/.config/outfitting/source/system/oci-agents
```
