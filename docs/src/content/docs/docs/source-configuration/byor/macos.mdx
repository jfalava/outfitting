---
title: macOS
description: Declare macOS Nix, Homebrew, and font paths in config.toml.
sidebar:
  order: 1
---

Select one macOS profile in the machine-local [configuration](/docs/source-configuration/):

```toml
schema = 1
[source]
repository = "https://git.example.com/team/machine-config.git"
ref = "main"
[macos]
profile = "workstation"
[profiles.workstation.macos]
brewfile = "ops/mac/Brewfile"
paths = ["modules/shared.nix"]
[profiles.workstation.macos.nix]
flake = "hosts/workstation"
attribute = "darwinConfigurations.workstation.system"
darwin = true
[profiles.workstation.macos.fonts]
manifest = "ops/mac/fonts.txt"
```

The flake directory is fetched as a tree; `paths` covers additional files. Paths are source-root-relative. For a local checkout, replace `repository` and `ref` with `path` (resolved relative to the config file). Run `outfitting-manager init` first to prepare state and fetch/validate the source; optionally run `outfitting-manager validate` to check it without refreshing. Use `outfitting-manager nix switch` for nix-darwin and `outfitting-manager apply` for the Brewfile.
