Select Windows profiles and optional shared components in the machine-local [configuration](/docs/source-configuration/):

```toml
schema = 1
[source]
path = "../machine-config"
[windows]
profiles = ["base", "dev"]
[windows.shared.scoop]
manifest = "ops/windows/scoop.txt"
[windows.shared.powershell]
path = "shell/Microsoft.PowerShell_profile.ps1"
[windows.shared.fonts]
manifest = "ops/windows/fonts.txt"
[windows.shared.registry]
path = "ops/windows/registry.reg"
[profiles.base.windows.winget]
manifest = "ops/windows/base.txt"
[profiles.dev.windows.winget]
manifest = "ops/windows/dev.txt"
```

Each selected profile declares its WinGet manifest. Shared declarations are optional and skipped when absent. All declaration paths are source-root-relative. For a remote Git source use `[source] repository` plus `ref` instead of `path`. Run `outfitting-manager validate` before `outfitting-manager setup`.
