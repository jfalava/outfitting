Select one Linux profile in the machine-local [configuration](/docs/source-configuration/). For a local checkout:

```toml
schema = 1
[source]
path = "../machine-config"
[linux]
profile = "workstation"
[profiles.workstation.linux]
paths = ["modules/shared.nix"]
[profiles.workstation.linux.apt]
manifest = "ops/linux/debian.txt"
[profiles.workstation.linux.pacman]
manifest = "ops/linux/arch.txt"
[profiles.workstation.linux.nix]
flake = "hosts/workstation"
attribute = "homeConfigurations.workstation.activationPackage"
```

Declare only the backends the machine needs. The Nix flake directory is fetched as a tree; `paths` adds other source files. Paths are relative to the source root. For a remote, replace `[source] path` with `repository` and `ref`. `outfitting-manager validate` checks the configuration before setup; `outfitting-manager setup` applies it. The config file can be selected globally with `--config` or `OUTFITTING_CONFIG`.
