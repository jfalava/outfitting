Outfitting Manager stores generated state that belongs to a machine but is not committed to Git. The CLI sends it to, and restores it from, the Lockfiles Worker.

## In this section

- [Overview](/docs/manager/overview) — architecture, storage, credentials, and local development.
- [Manager CLI](/docs/manager/cli) — commands for sending, restoring, and inspecting state.
- [Lockfiles Worker](/docs/manager/lockfiles-worker) — deployment and HTTP API reference.
