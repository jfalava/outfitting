Outfitting provisions a Windows development environment from the repository's package manifests, PowerShell profile, registry tweaks, and manager tools.

Start with the [installation instructions](/docs/windows/installation/) to bootstrap the machine, then use the [post-install steps](/docs/windows/post-install/) and [updates](/docs/windows/updates/) to finish and maintain it.

## Windows setup flow

1. Install one or more WinGet or Microsoft Store profiles.
2. Run the post-install script for Scoop and fonts.
3. Pull repository changes and run `Update-All` when you need to reconcile packages and inventories.

The Windows installer supports regular Windows hosts. Windows Subsystem for Linux has its own [installation instructions](/docs/wsl/installation/).
