## Prerequisites

- WinGet installed and current. Update it from the [Microsoft Store listing](https://apps.microsoft.com/detail/9NBLGGH4NNS1) when needed.
- An elevated PowerShell session. OpenSSH, firewall, and machine-level registry changes require elevation.
- If PowerShell blocks the hosted script, run `Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process`.

## Install a profile

Use a profile route from the hosted installer:

```powershell
irm win.jfa.dev/base | iex
irm win.jfa.dev/base+dev | iex
```

Regular profiles are canonical and include both WinGet and Microsoft Store packages. Store entries remain tagged as `msstore:<id>` in those manifests, and the CLI installs them from the Microsoft Store source. The retired `/msstore/*` and `/packages/*` installer routes no longer install anything. The installer downloads the verified Windows manager, applies the selected regular profile, fetches the configured profile and manifests without a repository clone, and performs the Windows host setup. Run the [post-install script](/docs/windows/post-install/) afterward to install Scoop and fonts.

For saved CLI selections, a mixed legacy selection such as `base,msstore-base` migrates to `base`. A standalone `msstore-base` selection errors because selecting `base` would also install non-Store packages; rerun with an explicit regular selection such as `outfit sync --profile base`.

For a compatible repository, set `OUTFITTING_MANIFEST_BASE_URL` and `OUTFITTING_MANIFEST_REF` before running the installer. Configure all repository routes later with [CLI config](/docs/cli/windows/config/).
