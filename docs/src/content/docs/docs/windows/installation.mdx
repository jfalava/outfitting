## Prerequisites

- **WinGet:** Installed and up to date. Update it from the [Microsoft Store](https://apps.microsoft.com/detail/9NBLGGH4NNS1) if needed.
- **PowerShell:** Run in an **elevated (Administrator)** session. Elevation is required for OpenSSH, Windows Firewall rules, and machine-level registry tweaks.

> [!TIP]
> If PowerShell blocks running the installation script, allow scripts for the current process:
>
> ```powershell
> Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
> ```

## Install

Run the hosted installer in an elevated PowerShell session:

```powershell
irm win.jfa.dev | iex
```

> [!WARNING]
> The existing installer still uses the retired raw-route configuration flow when setting up manager-managed packages. It must be migrated before that part of installation can use the BYOR-only manager. Installer scripts are unchanged by this migration.

Once complete, open a regular (non-elevated) PowerShell session and run the [post-install script](/docs/windows/post-install/) to install Scoop and developer fonts.

## Configure a source

The manager accepts a local checkout with a root `outfitting.json` or a remote Git repository explicitly mapped in the state-root `byor.json`.

For a local checkout:

```powershell
outfitting-manager validate --repo C:\src\my-machine-config --platform windows
outfitting-manager setup --repo C:\src\my-machine-config --profile base,dev
```

For a remote source, configure its repository, ref, WinGet paths, and optional shared components with [`outfitting-manager byor`](/docs/cli/byor/), then select its profiles:

```powershell
outfitting-manager byor
outfitting-manager setup --profile base,dev
```

See [BYOR for Windows](/docs/source-configuration/byor/windows/) for composable profiles and optional Scoop, PowerShell, fonts, and registry declarations. For command-level workflows, see the [Windows CLI reference](/docs/cli/windows/).
