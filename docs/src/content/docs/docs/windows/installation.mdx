## Prerequisites

- **WinGet:** Installed and up to date. Update it from the [Microsoft Store](https://apps.microsoft.com/detail/9NBLGGH4NNS1) if needed.
- **PowerShell:** Run in an **elevated (Administrator)** session. Elevation is required for OpenSSH, Windows Firewall rules, and machine-level registry tweaks.

> [!TIP]
> If PowerShell blocks running the installation script, allow scripts for the current process:
>
> ```powershell
> Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
> ```

## Install

Run the hosted installer in an elevated PowerShell session:

```powershell
irm win.jfa.dev | iex
```

> [!WARNING]
> The post-install script runs `init` and `apply` against the configured TOML source. Configure `config.toml` before running that script.

Once complete, open a regular (non-elevated) PowerShell session and run the [post-install script](/docs/windows/post-install/) to install Scoop and developer fonts.

## Configure a source

Declare `[source] path` or remote `repository` and `ref`, plus `[windows] profiles`, in the machine-local [config.toml](/docs/source-configuration/).

```powershell
outfitting-manager init
outfitting-manager validate # optional check of the fetched source
outfitting-manager apply --yes
```

See [Windows configuration](/docs/source-configuration/byor/windows/) for composable profiles and optional Scoop, PowerShell, fonts, and registry declarations. For command-level workflows, see [init](/docs/cli/init/), [apply](/docs/cli/apply/), and the [Windows CLI reference](/docs/cli/windows/).
