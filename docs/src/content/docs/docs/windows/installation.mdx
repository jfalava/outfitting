## Prerequisites

- WinGet installed and current. Update it from the [Microsoft Store listing](https://apps.microsoft.com/detail/9NBLGGH4NNS1) when needed.
- An elevated PowerShell session. OpenSSH, firewall, and machine-level registry changes require elevation.

> If PowerShell blocks the hosted script, run `Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process`.

## Install a profile

Use a profile route from the hosted installer:

```powershell
irm win.jfa.dev | iex
```

> Note: the installer has a mix of WinGet packages and Microsoft Store packages

Run the [post-install script](/docs/windows/post-install/) afterward to install Scoop and fonts.

## BYOR (Bring Your Own Repo)

For a hosted repository that still uses the legacy monorepo layout, set `OUTFITTING_MANIFEST_BASE_URL` and `OUTFITTING_MANIFEST_REF` before running the installer. Configure repository routes later with [CLI config](/docs/cli/windows/config/).

For a local checkout that owns an `outfitting.json` contract, validate and apply without requiring Outfitting’s default `packages/windows/{profile}.txt` layout:

```powershell
outfitting-manager validate --repo C:\src\my-machine-config --platform windows
outfitting-manager setup --repo C:\src\my-machine-config --profile base,dev
```

See [BYOR for Windows](/docs/source-configuration/byor/windows/) for the contract schema, composable profiles, and when `config.json` routes still apply.

For command-level workflows, see the [Windows CLI reference](/docs/cli/windows/).
