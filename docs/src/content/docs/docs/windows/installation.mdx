Outfitting provisions Windows from WinGet and Scoop manifests, a PowerShell profile, registry tweaks, and the compiled manager.

## Prerequisites

- WinGet installed and current. Update it from the [Microsoft Store listing](https://apps.microsoft.com/detail/9NBLGGH4NNS1) when needed.
- An elevated PowerShell session. OpenSSH, firewall, and machine-level registry changes require elevation.
- If PowerShell blocks the hosted script, run `Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process`.

## Install a profile

Use a profile route from the hosted installer:

```powershell
irm win.jfa.dev/base | iex
irm win.jfa.dev/base+dev | iex
```

Profiles can include both WinGet and Microsoft Store packages. Store entries are tagged as `msstore:<id>` in manifests, and the CLI installs them from the Microsoft Store source. The installer downloads the verified Windows manager, fetches the configured declarations without cloning the repository, runs setup for the selected profile bundles, and performs Windows host setup. Run the [post-install script](/docs/windows/post-install/) afterward to install Scoop and fonts.

For a compatible repository, set `OUTFITTING_MANIFEST_BASE_URL` and `OUTFITTING_MANIFEST_REF` before running the installer. Configure all repository routes later with [CLI config](/docs/cli/windows/config/).

For command-level workflows, see the [Windows CLI reference](/docs/cli/windows/).
