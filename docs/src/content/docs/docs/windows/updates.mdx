The Windows manager stores configuration, fetched manifests, and `windows.lock.json` under `%USERPROFILE%\.config\outfitting`. You can set `OUTFITTING_STATE_ROOT` to choose a different directory.

## Upgrade installed packages (`update`)

Use `update` to upgrade existing software to the latest versions. Note that `update` only upgrades packages you already have; to install newly added profile packages, use [`apply`](#apply-profile-changes-apply).

```powershell
# Upgrade all packages (WinGet and Scoop)
outfitting-manager update all

# Upgrade only WinGet packages
outfitting-manager update winget

# Upgrade Scoop packages without pushing lockfile changes
outfitting-manager update scoop --no-push
```

`update all` updates WinGet first, then Scoop, and finally synchronizes `windows.lock.json`. It will continue through errors and exit with a non-zero code if any step fails. Lockfile changes are pushed to remote state by default; pass `--no-push` to keep them local.

## Apply profile changes (`apply`)

When you add new packages to your profile manifests, run `apply` to install them:

```powershell
# Install missing packages for selected profiles
outfitting-manager apply --profile base,dev

# Apply only WinGet packages
outfitting-manager apply --profile base,dev --winget-only
```

## Update Outfitting and dependencies

- **Outfitting CLI:** Update the compiled manager binary by running `outfitting-manager upgrade`.
- **Bun packages:** Update global Bun packages with `bun update -g`.

For the complete command reference, see the [Windows CLI reference](/docs/cli/windows/).
