Run the post-install script in a **new, non-elevated** PowerShell session:

```powershell
irm win.jfa.dev/post-install | iex
```

> [!IMPORTANT]
> Do not run this script as Administrator. Scoop intentionally aborts if run with elevated privileges.

> [!WARNING]
> The post-install script may still use the older implicit/raw-route source flow. Configure `config.toml` before manual manager setup; independent Scoop and font steps remain available.

### What gets configured

1. **Scoop:** Installs the [Scoop](https://scoop.sh/) package manager if not already present.
2. **Package reconciliation:** Runs `outfitting-manager setup` to apply Scoop manifests and configuration.
3. **Public fonts:** Installs open-source developer fonts using FontGet.
4. **Licensed fonts (optional):** Downloads and extracts licensed font archives to `%USERPROFILE%\Downloads\fonts` if configured.

For deeper command options, see [CLI setup](/docs/cli/setup/) and [CLI fonts](/docs/cli/fonts/).
