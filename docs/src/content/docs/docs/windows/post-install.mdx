Run the post-install script in a new PowerShell session:

```powershell
irm win.jfa.dev/post-install | iex
```

It installs Scoop when needed, runs the Windows manager setup, installs the public font list, and optionally downloads the protected licensed-font archive to `%USERPROFILE%\Downloads\fonts`.

Manager download failures are best-effort. Scoop and public-font failures return a failure status after the remaining work; private-font failures are reported but do not fail the script.

See [Windows CLI setup](/docs/cli/windows/setup/) and [CLI fonts](/docs/cli/fonts/) for the detailed command behavior.
