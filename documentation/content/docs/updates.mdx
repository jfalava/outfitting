---
title: Updates
description: Update workflows after installation for WSL, macOS, and Windows.
---

## WSL

Quick update:

```bash
curl -L wsl.jfa.dev | bash
```

Update local configuration after editing files in `~/.config/outfitting/repo`:

```bash
git pull
hm-sync
```

Update packages:

```bash
hm-update
update-all
```

Re-run post-install work, including the Cloudflare Access-protected licensed
font installation:

```bash
curl -L mac.jfa.dev/post-install | bash
```

Other update modes:

```bash
curl -L wsl.jfa.dev | bash -s -- --update-only
curl -L wsl.jfa.dev | bash -s -- --full-install
```

## macOS

Update local configuration after editing files in `~/.config/outfitting/repo`:

```bash
git pull
outfit sync
hm-sync
```

Update packages:

```bash
outfit upgrade
hm-update
update-all
```

## Windows

Update the repository-managed configuration and rebuild `outfitting-manager`:

```powershell
Set-Location "$HOME\.config\outfitting\repo"
git pull
bun run --cwd manager/cli build:windows-x64
```

The PowerShell profile entry points and `C:\bin\outfitting-manager.exe` are
symlinks to files in the repository, so they do not need to be downloaded or
copied again. Open a new PowerShell session after pulling, or reload the profile
in the current session:

```powershell
. $PROFILE
```

Update packages and record the current Windows package inventories:

```powershell
Update-All
```

Re-run post-install work, including downloading and extracting the Cloudflare
Access-protected licensed fonts to `%USERPROFILE%\Downloads\fonts` for optional
manual installation:

```powershell
irm win.jfa.dev/post-install | iex
```

## Install or Update Bun Global Packages (WSL/macOS)

WSL:

```bash
curl -fsSL wsl.jfa.dev/packages/bun | xargs -I {} bun install -g {}
```

macOS:

```bash
curl -fsSL mac.jfa.dev/packages/bun | xargs -I {} bun install -g {}
```
