# Outfitting manager CLI

Portable local maintenance CLI for Outfitting.

Start with the shared command references for [init](https://outfitting.jfa.dev/docs/cli/init/), [apply](https://outfitting.jfa.dev/docs/cli/apply/), [Nix](https://outfitting.jfa.dev/docs/cli/nix/), [update](https://outfitting.jfa.dev/docs/cli/update/), [self-update](https://outfitting.jfa.dev/docs/cli/self-update/), [sync](https://outfitting.jfa.dev/docs/cli/sync/), and [status](https://outfitting.jfa.dev/docs/cli/status/).

Platform details: [Windows](https://outfitting.jfa.dev/docs/cli/windows/), [Linux](https://outfitting.jfa.dev/docs/cli/linux/), and [macOS](https://outfitting.jfa.dev/docs/cli/macos/).
