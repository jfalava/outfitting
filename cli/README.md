# Outfitting manager CLI

Portable local maintenance CLI for Outfitting.

Start with the shared command references for [init](https://outfitting.jfa.dev/docs/cli/init/), [setup](https://outfitting.jfa.dev/docs/cli/setup/), [apply](https://outfitting.jfa.dev/docs/cli/apply/), [sync](https://outfitting.jfa.dev/docs/cli/sync/), [update](https://outfitting.jfa.dev/docs/cli/update/), and [status](https://outfitting.jfa.dev/docs/cli/status/).

Platform details: [Windows](https://outfitting.jfa.dev/docs/cli/windows/), [Linux](https://outfitting.jfa.dev/docs/cli/linux/), and [macOS](https://outfitting.jfa.dev/docs/cli/macos/).
